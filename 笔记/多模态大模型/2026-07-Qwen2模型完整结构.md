## 15. Qwen2 模型完整结构 (2026.07)

> 来源：逐行分析 `modeling_qwen2.py`，Decoder-only Transformer

### 整体架构

```
输入: input_ids (B, N)
    │
    ▼
embed_tokens ─── nn.Embedding(vocab_size, hidden_size)
    │               查表得到每个 token 的向量
    ▼
┌──────────────────────────────────────────────────────────┐
│  Qwen2DecoderLayer × num_hidden_layers                   │
│                                                          │
│  residual ───────────────────────────────────► + ─┐      │
│  │                                                │      │
│  input_layernorm (RMSNorm)                        │      │
│  │                                                │      │
│  self_attn ──────────────────────────────────► + ─┤      │
│  │  ├─ q_proj:  hidden → q_heads × head_dim       │      │
│  │  ├─ k_proj:  hidden → kv_heads × head_dim      │ GQA  │
│  │  ├─ v_proj:  hidden → kv_heads × head_dim      │      │
│  │  ├─ RoPE (Q/K 注入位置信息)                    │      │
│  │  ├─ KV Cache → concat(历史K, 当前K) → 更新缓存 │      │
│  │  │            concat(历史V, 当前V)             │      │
│  │  ├─ repeat_kv (K/V 复制对齐 Q 头数)            │      │
│  │  ├─ Q @ [K_hist|K_cur]^T / √d   ← 注意力分数   │      │
│  │  ├─ + mask → softmax                           │      │
│  │  ├─ @ [V_hist|V_cur]            ← 加权求和     │      │
│  │  └─ o_proj:  多头输出 → hidden                 │      │
│  │                                                  │      │
│  residual ───────────────────────────────────► + ─┐  │      │
│  │                                                │  │      │
│  post_attention_layernorm (RMSNorm)               │  │      │
│  │                                                │  │      │
│  mlp (SwiGLU) ───────────────────────────────► + ─┘  │      │
│     ├─ gate_proj: hidden → intermediate              │      │
│     ├─ up_proj:   hidden → intermediate              │      │
│     ├─ SiLU(gate) * up                               │      │
│     └─ down_proj: intermediate → hidden              │      │
│                                                          │
│  ┌─ KV Cache 逐层读写 ─────────────────────────────┐     │
│  │ 训练: 不缓存                                    │     │
│  │ 推理: 每层 attn 结束后 K_cur,V_cur 追加进缓存   │     │
│  │       下一 token 来时 concat 历史 K,V 一起算     │     │
│  └─────────────────────────────────────────────────┘     │
└──────────────────────────────────────────────────────────┘
    │
    ▼
norm (RMSNorm) ─── 最后归一化
    │
    ▼
lm_head ─── nn.Linear(hidden_size, vocab_size), bias=False
    │         与 embed_tokens 共享权重 (tied weights)
    ▼
输出: logits (B, N, vocab_size) → 每个位置预测下一个 token

loss = CrossEntropyLoss(shift(logits), shift(labels))
```

### 关键设计

| 设计项 | 做法 |
|--------|------|
| 归一化 | Pre-Norm + RMSNorm（只缩放不去均值） |
| 激活函数 | SiLU (Swish) → SwiGLU MLP |
| 位置编码 | 1D RoPE，预计算 cos/sin 缓存查表，推理超长序列时动态扩展 |
| 注意力 | GQA：28 个 Q 头 / 4 个 K/V 头，KV 缓存减少 7 倍 |
| KV Cache | 每层存 K/V 原始投影结果(不加权)，推理时 concat 历史，每次用新 Q 动态加权所有历史 V |
| 注意力后端 | eager / flash_attn_2 / sdpa / magi 四种可切换 |
| 权重绑定 | embed_tokens.weight = lm_head.weight |
| 训练优化 | gradient checkpointing 逐层重算省激活显存 |

### 各模块职责

| 模块 | 类名 | 职责 |
|------|------|------|
| RMS 归一化 | `Qwen2RMSNorm` | `x / RMS(x) * weight`，去大小留形状 |
| 旋转位置编码 | `Qwen2RotaryEmbedding` | 预计算 cos/sin 缓存，按位置查表 |
| SwiGLU MLP | `Qwen2MLP` | `down(SiLU(gate(x)) * up(x))`，门控信息流 |
| 注意力基类 | `Qwen2Attention` | Q/K/V 投影 + RoPE + GQA + masked softmax |
| Flash Attn | `Qwen2FlashAttention2` | pad→unpad→varlen_flash_attn→pad 回来 |
| SDPA Attn | `Qwen2SdpaAttention` | `F.scaled_dot_product_attention` 自动选后端 |
| Magi Attn | `Qwen2MagiAttention` | 范围稀疏注意力，支持 MTP packing 训练 |
| Decoder 层 | `Qwen2DecoderLayer` | Pre-Norm + Attn + Pre-Norm + MLP |
| Transformer | `Qwen2Model` | embed + N×layers + norm |
| 因果 LM | `Qwen2ForCausalLM` | Qwen2Model + lm_head + loss |

### 数据流

```
input_ids (B, N)
  → embed_tokens → (B, N, hidden)
  → N × DecoderLayer:
      norm → attn(Q/K/V投影→RoPE→KV Cache拼接→repeat_kv→flash/sdpa/eager→o_proj) → +residual
      norm → mlp(gate/up→SiLU→*) → down → +residual
  → norm
  → lm_head → (B, N, vocab_size) logits
  → shift logits/labels → CrossEntropyLoss

推理时: 每层 attn 结束后 K_cur,V_cur 追加进 KV Cache
        下一 token 来时 concat(历史K,当前K)、concat(历史V,当前V) 一起算 attention
        历史 token 不需要重新走 embed → transformer，只存 K/V 原始向量
```

### 对比 MoonViT (Vision Encoder)

| | Qwen2 (LLM) | MoonViT (ViT) |
|---|---|---|
| 类型 | Decoder-only | Encoder-only |
| 位置编码 | 1D RoPE | 2D RoPE (row+col) |
| 注意力 | causal=True | causal=False |
| 序列格式 | (B, N, d) 或 packed | packed (Σh*w, d) + cu_seqlens |
| MLP | SwiGLU (3 条线) | Standard (2 条线) |
| 归一化 | RMSNorm | LayerNorm |
| 输出 | logits 预测下一个 token | visual features 送给 LLM |
| mask | causal 三角形 | block-diagonal 块对角 |
