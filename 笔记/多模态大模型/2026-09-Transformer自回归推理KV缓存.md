> 来源：梳理"自回归每层 KV 缓存到底存的是什么"。一句话：**每层的 KV 缓存存的是该层为每个历史 token 算出来的"原始 K/V 投影向量"，不是聚合后的上下文结果 h_l**。

### 一、单层内部流程（第 l 层，当前 token t）

```
输入 h_{l-1}^{(t)}（第1层即 token embedding）
  1. Q_l = W_Q_l·h_{l-1}；K_l = W_K_l·h_{l-1}；V_l = W_V_l·h_{l-1}
  2. ★ K_l、V_l 立刻写入第 l 层的 KV 缓存（供未来 token 用）★
  3. 取缓存全部历史 K/V：K_cache=[K_l^{(1..t-1)}]，V_cache=[...]
  4. attention 输出 = softmax(Q_l · K_cacheᵀ) · V_cache   ← 聚合上下文
  5. 过 MLP + 残差 + LayerNorm → 输出 h_l^{(t)}（传给 l+1 层）
```

### 二、为什么存"原始投影"，不存"聚合后的"

| 问题 | 答案 |
| :--- | :--- |
| KV 缓存存什么？ | **原始投影向量** K_l / V_l（当前 token 刚算出的） |
| 聚合后的 attention 输出存哪？ | **不存**，作为本层输出 h_l 往下传，用完即过 |
| 为何不能存聚合值？ | 未来 token 需要**自己重新算与每个历史 token 的相似度权重**；存聚合值 = 权重已被别人平均，逐 token 信息丢失 |
| 为何不直接复用 h_l（已含上下文）？ | 每层处**不同特征空间**，要在该层自己的语义空间里重新算 attention 分布；l+1 层不复用 l 层的 attention 结果 |

### 三、多层数据流与生成（推理）阶段

- **每层各有一份独立缓存**：Token 走过 L 层，每层各算一次 K_l/V_l 并写入**自己的**第 l 层缓存。
- **自回归生成第 T+1 个 token 时**：只对当前 token 算 Q_l，再对它 attend 各层缓存的全部历史 K/V → h_L 进 LM Head。
- **纯解码（推理）阶段不再写入新 K/V**；写入发生在**训练 / 预填充（prefill）**阶段，供后续 token 使用。

### 四、为什么必须同时存 K 和 V

- **K（Key）**：和 Q 点积 → 注意力权重（"跟谁相关"）
- **V（Value）**：加权求和 → 聚合内容（"取到什么信息"）
- 缺一不可：只有 V 无 K = 不知权重怎么分；只有 K 无 V = 有权重没内容可加权。

### 五、一句核心总结

> **每层 KV 缓存 = 该层为每个历史 token 算出的原始 K/V 投影向量**，目的是让未来 token 在该层特征空间里能自由重新分配注意力权重；每层输出 h_l 是聚合结果，只作下一层输入，**不进缓存**。
