## 24. 线性 vs 非线性：深度学习的第一性原理 (2026.07)

> 来源：理解 Transformer 中各模块本质——线性在融合权重，非线性在提升特征

### 一句话总结

> **线性层负责融合、重组、加权已有信息；非线性层负责创造、筛选、激活新的特征。没有非线性，再多层也只是等价的线性变换，无法解决复杂问题。**

### 核心对比

| 特性 | 线性变换 | 非线性变换 |
|------|---------|-----------|
| 核心作用 | 融合、重组、加权已有信息 | 创造、筛选、激活新的模式 |
| 操作 | 矩阵乘法、加权求和 | 激活函数（ReLU/GELU/Swish）、Softmax、门控 |
| 信息流 | 信息被混合、压缩或扩展 | 信息被"门控"、筛选、增强 |
| 能新增信息吗？ | ❌ 不能，只是重新组合 | ✅ 能！引入新的非线性结构 |

### Transformer 中的线性/非线性分工

```
输入 x
    │
    ├── LayerNorm (预处理，非严格线性/非线性)
    │
    ├── Q = x·W_q  → 线性（融合x的各维度生成Q）
    ├── K = x·W_k  → 线性
    ├── V = x·W_v  → 线性
    │
    ├── Q·K^T  → 线性（计算相似度，融合Q和K的信息）
    │
    ├── Softmax  → 非线性！（将分数转为概率分布，"强者更强"）
    │
    ├── 概率 × V  → 线性（加权求和，融合V的各部分）
    │
    ├── Concat  → 线性（合并多头信息）
    ├── W_o  → 线性（混合多头发现）
    │
    ├── + 残差  → 线性（叠加原始x）
    │
    ├── FFN 升维 (W_up)  → 线性（扩展特征空间）
    │
    ├── 门控/激活 (GELU/SiLU)  → 非线性！（筛选重要特征，抑制不重要特征）
    │
    └── FFN 降维 (W_down)  → 线性（压缩回原维度，提炼关键信息）
```

### 关键非线性机制

**① Softmax：注意力的"聚焦"**

```python
scores = [0.5, 0.6, 0.7]
weights = softmax(scores)  # [0.29, 0.32, 0.39]
# 原本差距不大，Softmax 后差距更明显
```

作用：让注意力权重变成概率分布，突出重点，抑制次要。

**② GELU/ReLU：FFN 的"特征开关"**

```python
x = [-2.3, -1.1, 0.5, 0.8, 3.2]
gelu(x) ≈ [-0.08, -0.08, 0.35, 0.65, 3.0]
#    几乎清零  几乎清零  保留  增强  增强
```

作用：决定哪些特征有用（保留/增强），哪些无用（抑制/清零），这是特征"升华"的核心。

### 类比：工厂流水线

| 环节 | 对应操作 | 本质 |
|------|---------|------|
| 把原材料放在一起 | 线性变换 | 融合、重组 |
| 评估哪些材料重要 | Softmax（非线性） | 筛选、聚焦 |
| 按重要性组装产品 | 加权求和（线性） | 融合、加权 |
| 专家会诊（多头） | Concat + W_o（线性） | 多方意见融合 |
| 化学处理，产生新特性 | 激活函数（非线性） | **创造新特征！** |
| 包装出厂 | 线性降维 | 压缩、提炼 |

### 为什么非线性是"智能"的来源？

**没有非线性**：无论多少层线性层堆叠，数学上等价于一个大的线性变换。

```python
f(x) = W₃·W₂·W₁·x = W_total·x  ← 还是线性！
```

**有了非线性**：每一层都能创造新的特征表示，网络可以逼近任意复杂函数（通用近似定理）。

```python
f(x) = W₃·σ(W₂·σ(W₁·x))  ← σ 是非线性激活，每一层都产生新的特征空间
```

### 最终结论

```
线性 = 融合/重组信息
非线性 = 创造/提升特征
```

**记忆口诀**：

```
线性层，做融合，权重矩阵来相乘
非线性，造特征，激活门控做筛选
Softmax 聚焦注意力，GELU 开关升特征
没有非线深如浅，有了非线智乃生
```
