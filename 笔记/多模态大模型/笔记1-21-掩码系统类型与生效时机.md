### 21.2 ① text_self_attention_masks（子句掩码）

**生成：** `generate_masks_with_special_tokens_and_transfer_map()` — `bertwarper.py:224-273`

以 `[CLS]`/`[SEP]`/`.`/`?` 为分隔符，生成块对角矩阵：

```
输入: [CLS] a cat . a dog [SEP]
掩码:
       [CLS] a cat . a dog [SEP]
[CLS]   ✓
a          ✓  ✓   ✓
cat        ✓  ✓   ✓
.          ✓  ✓   ✓
a                     ✓  ✓   ✓
dog                   ✓  ✓   ✓
[SEP]                        ✓
```

**形状：** `[B, L, L]`，bool，True=可以关注

**使用位置（两处）：**

| 使用位置 | 代码 | 方式 |
|---|---|---|
| BERT forward | `groundingdino.py:287` | 直接替换 `attention_mask`（HF 语义：True=可见） |
| Text Self-Attn (Encoder) | `transformer.py:515` | `src_mask=~text_self_attention_masks`（PyTorch 语义相反，取反） |

### 21.3 ② text_token_mask（文本 padding 掩码）

**生成：** `tokenized.attention_mask.bool()` — `groundingdino.py:299`

标记哪些 token 是真实文本，哪些是 `<PAD>` 填充。

**形状：** `[B, L]`，bool，True=有效 token

**使用位置（三处）：**

| 使用位置 | 代码 | 方式 |
|---|---|---|
| BiAttention 融合 | `transformer.py:508` | `attention_mask_l=text_attention_mask`（~text_token_mask，True=padding） |
| Text Self-Attn | `transformer.py:516` | `src_key_padding_mask=text_attention_mask` |
| ContrastiveEmbed | `utils.py:263` | `res.masked_fill_(~text_token_mask, -inf)` |

### 21.4 ③ mask_flatten（图像 padding 掩码）

**生成：** backbone 输出的 `feat.mask` 展平 — `transformer.py:318`

```python
mask = mask.flatten(1)  # [B, H, W] → [B, H*W]
```

**形状：** `[B, sum(H×W)]`，bool，True=padding

**使用位置（两处）：**

| 使用位置 | 代码 | 方式 |
|---|---|---|
| Encoder Deformable Self-Attn | `transformer.py:347,529` | `key_padding_mask=mask_flatten` |
| Decoder Deformable Cross-Attn | `transformer.py:417` | `memory_key_padding_mask=mask_flatten` |

### 21.5 ④ cate_to_token_mask_list（类别→token 映射）

**生成：** `generate_masks_with_special_tokens_and_transfer_map()` — `bertwarper.py:247-266`

对每个子句（类别），标记哪些 token 属于它：

```
caption: "cat . dog"
类别0: [0, 1, 0, 0, 0]  → token[1]="cat"
类别1: [0, 0, 0, 1, 0]  → token[3]="dog"
```

**形状：** List of `[num_categories, L]`，bool

**使用位置：** 不参与 forward，训练时用于构建 positive_map（类别标签 → token 位置的映射）。

### 21.6 ⑤ attn_mask（DN 去噪掩码）

**生成：** DN（Denoising）训练时动态生成

将匹配 query 和 DN query 隔离开，防止匹配 query 看到加噪后的 DN 信息，破坏对比学习的纯度。

**形状：** `[num_queries, num_queries]`

**使用位置：** Decoder Self-Attention — `transformer.py:423` `tgt_mask=attn_mask`

### 21.7 掩码生效时机

所有掩码都在 **softmax 之前**生效，通过给被掩蔽位置加 -∞：

```
scores = Q @ K^T / sqrt(d)
scores = scores + mask_bias(-∞)     ← 掩码在这里
weights = softmax(scores)
```

子句掩码和 padding 掩码叠加使用：先被子句掩码排除跨块 token，再被 padding 掩码排除填充 token，两者是 AND 关系。
