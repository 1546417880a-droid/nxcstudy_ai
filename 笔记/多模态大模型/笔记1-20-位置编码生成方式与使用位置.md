**所属：** 模型架构 / 位置编码

Grounding DINO 有三套独立的位置编码，服务于不同模块。

### 20.1 文本位置编码（Text Position Encoding）

**生成：** 两步

1. `generate_masks_with_special_tokens_and_transfer_map` 生成 `position_ids`（`bertwarper.py:246-258`）：
   - 每个子句独立从 0 编号
   - 输入 `[CLS] a cat . a dog [SEP]` → position_ids = `[0, 0, 1, 2, 0, 1, 0]`

2. `get_sine_pos_embed()` 将 position_ids 转成正弦编码（`utils.py:24-53`）：
   ```python
   pos_text = position_ids[..., None]                    # [B, L, 1]
   pos_text = get_sine_pos_embed(pos_text, num_pos_feats=256)  # [B, L, 256]
   ```

**方法：** 正弦绝对位置编码（Sinusoidal），频率公式：`1 / (10000^(2i/d))`

**使用位置：** Encoder 的 Text Self-Attention 层（`transformer_vanilla.py:113`）

```python
q = k = self.with_pos_embed(src, pos)    # src + pos，加在 W_Q/W_K 投影之前
src2 = self.self_attn(q, k, value=src)   # V = src（内容），不含位置
```

### 20.2 图像位置编码（Image Position Encoding）

**生成：** Backbone 配套的 PositionEmbedding 模块（`backbone.py:197-220`）

- 根据每个特征图的 2D 空间坐标生成正弦位置编码
- 多尺度特征每层有独立的 `pos_embed`

**方法：** 2D 正弦位置编码 + 层级嵌入

```python
# transformer.py:319-324
pos_embed = pos_embed.flatten(2).transpose(1, 2)  # [B, H*W, 256]
if num_feature_levels > 1:
    lvl_pos_embed = pos_embed + level_embed[lvl]   # 加上层级标识
```

**使用位置：** Encoder Deformable Self-Attention（`transformer.py:526-527`）

```python
output = self.layers[layer_id](
    src=output, pos=pos, ...   # pos 传入编码器层
)
# 层内: query = src + pos，K 和 V = src（不加 pos）
```

### 20.3 Query 位置编码（Decoder Query Position Encoding）

**生成：** 从参考点坐标动态生成（`transformer.py:566-568`）

```python
query_sine_embed = gen_sineembed_for_position(reference_points)  # 正弦编码
query_pos = self.ref_point_head(query_sine_embed)                # MLP 映射
```

**方法：** 基于参考框坐标 `(cx, cy, w, h)` 的 2D 正弦编码 → MLP 投影

**使用位置：** Decoder 的 Self-Attention 和 Cross-Attention（`transformer.py:686-704`）

```python
# Self-Attention:
q = k = self.with_pos_embed(tgt, tgt_query_pos)  # tgt + query_pos

# Text Cross-Attention:
self.ca_text(
    self.with_pos_embed(tgt, tgt_query_pos),  # Q
    memory_text, memory_text)                  # K, V（不加 pos）

# Deformable Cross-Attention:
self.cross_attn(
    query=self.with_pos_embed(tgt, tgt_query_pos),  # Q
    value=memory)                                    # V（不加 pos）
```

### 20.4 三套位置编码对比

| | 文本位置编码 | 图像位置编码 | Query 位置编码 |
|---|---|---|---|
| **来源** | position_ids（每子句独立编号） | 2D 空间坐标 + 层级嵌入 | 参考框坐标 (cx,cy,w,h) |
| **生成函数** | `get_sine_pos_embed` | Backbone PositionEmbedding | `gen_sineembed_for_position` + MLP |
| **类型** | 正弦绝对位置 | 2D 正弦 + learnable level_embed | 2D 正弦 → MLP 映射 |
| **使用位置** | Text Self-Attn (Encoder) | Deformable Self-Attn (Encoder) | Decoder 所有 Attention |
| **加法时机** | W_Q/W_K 投影**之前** | 编码器层内 Q = src + pos | 解码器层内 Q = tgt + query_pos |
| **V 是否加位置** | ❌ 不加 | ❌ 不加 | ❌ 不加 |

### 20.5 为什么 V 都不加位置编码？

位置信息的目的是影响**"谁关注谁"**（Q·K），不是影响**"关注后取什么内容"**（V）。如果 V 加了位置编码，attention 的输出会携带固定的位置偏置，与内容无关，反而干扰后续处理。
