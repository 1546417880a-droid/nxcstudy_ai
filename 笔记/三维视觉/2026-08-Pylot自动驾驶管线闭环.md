## Pylot 自动驾驶管线闭环理解 (2026.08)

> 来源：学习 Pylot 代码库时整理的心智模型

### 闭环总览

```
真实世界
   │ ① 传感器感知（尽量获取真实世界）
   ▼
检测 / 分割模型（各种模型去检测分割这个世界）
   │ ②
   ▼
跟踪 / 预测（根据检测结果去跟踪和预测）
   │ ③
   ▼
感知到的世界状态（模拟 / 表示出来的"真实世界"）
   │ ④ 根据这个结果做决策
   ▼
生成运动指令
   │ ⑤ 车辆执行运动指令 → 更新真实世界
   ▼
真实世界被更新
   │ ⑥ 传感器再次刷新 → 进入循环
   └────────────────────────────────┘
```

### 一句话版

真实世界 → 传感器 → 检测/分割 → 跟踪/预测 → 感知到的世界状态 → 决策 → 运动指令 → 车辆执行、世界更新 → 传感器再次刷新 → 循环。

### 关键点

1. **传感器获取的是"真实世界"**，模型构建的是"模拟/表示出来的世界"（感知到的世界状态）——两者要区分开。
2. 检测/分割是**当前帧**的感知；跟踪/预测把当前感知结果放到**时间维度**上（目标是谁、接下来往哪走）。
3. 决策生成运动指令，依赖的是"感知到的世界"，而不是"真实世界"本身。
4. 执行指令会让真实世界变化，于是传感器刷新到的数据也变，闭环成立。

### 对应 Pylot 模块（待对照源码验证）

| 环节 | Pylot 对应模块 |
|---|---|
| 传感器感知 | camera / lidar 等传感器 |
| 检测 / 分割 | detection / segmentation |
| 跟踪 / 预测 | tracking / prediction（轨迹预测） |
| 决策 | planning |
| 运动指令 | control（油门/转向/刹车） |
| 执行 / 世界更新 | CARLA 模拟器物理更新 |

> 注：上表模块映射待对照 pylot 源码逐一验证。
