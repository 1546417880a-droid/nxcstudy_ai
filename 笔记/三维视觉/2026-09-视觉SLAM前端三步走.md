## 视觉 SLAM 前端"三步走"总结（特征提取/匹配/三角化+外参）(2026.09)

> 来源：梳理视觉 SLAM / VO 最核心的前端流程。一句话：**图像 → 提特征 → 匹配点对 → 三角化出点云 + 解出相机外参**。这是整个 SLAM 持续运行的骨架。

### 一、三步走总览

```
图像A + 图像B
   ↓ ① 提取 ORB 特征
  A → 特征点A + 描述子A；B → 特征点B + 描述子B
   ↓ ② 特征匹配
  描述子A vs 描述子B → 距离最小的点对 → 2D-2D 匹配点对
   ↓ ③ 用匹配点对做两件事
  ├── ① 三角化 → 生成 3D 点云
  └── ② 计算相机运动 → 得到 B 相对 A 的相机外参
```

### 二、两种处理路径（取决于深度是否已知）

| 相机类型 | 顺序 | 工具 |
|---|---|---|
| **单目**（无深度） | 先求**外参** → 再**三角化**点云 | 对极几何 → 三角测量 |
| **双目 / RGB-D**（有深度） | 先求**点云** → 再求**外参** | 视差/深度图 → PnP |

- **单目注意**：初始化时求出的平移是**尺度不确定**的（归一化平移）——只知道相对比例，不知道真实米数。
- **PnP**（Perspective-n-Point）：用 3D 点云 + 其在下一幅图的 2D 像素坐标，直接解位姿。

### 三、外参到底指什么

- 外参 = **旋转矩阵 R + 平移向量 t**。
- 表示：**第二幅图拍摄时，相机坐标系相对于第一幅图（世界系原点）的位置和朝向**——即 **B 相对 A 的位姿变换**。你理解的"以第一个相机坐标系为基准"准确。

### 四、系统持续运行模式

```
【第1帧】初始化，建立初始地图
【第2帧】提特征 → 与第1帧匹配 → 计算外参（跟踪）+ 三角化新点入图
【第3帧】提特征 → 与第2帧匹配（或与地图匹配）→ 计算外参 + 三角化新点
   ... 循环
```

> 后续的局部优化、回环检测、全局优化，都是在这个骨架上构建的。
