## 3D Gaussian Splatting vs SLAM 认知总结 (2026.08)

> 来源：讨论"3DGS 和传统 SLAM 是不是都在从观测数据构建空间表示"时整理。结论：两者有共同骨架，但建模目标不同——3DGS 是**可渲染场景表示**，SLAM 是**几何地图 + 位姿估计**。

### 一、两者共同框架

```
                 传感器观测
                     │
             ┌───────┴───────┐
             ↓               ↓
            SLAM            3DGS
             │               │
             ↓               ↓
        几何空间表示       可渲染空间表示
             │               │
             └───────┬───────┘
                     ↓
                 Scene Model
```

直觉"Gaussian 空间由点云扩充出来、SLAM 空间由 SLAM 建立"**方向正确**，但细节要精确。

### 二、Gaussian 不是"变胖的点云"

3DGS 可以从 SfM/COLMAP 稀疏点云初始化，但每个 Gaussian 不是普通点，而是一个带属性的小椭球：

```
Gaussian = 位置 μ + 空间尺度/协方差 Σ + 不透明度 α + 颜色（View-dependent）
```

训练中不断 split / clone / prune / optimize，最终 Gaussian 数量与分布**不等于**原始点云。

### 三、核心区别：SLAM vs 3DGS

| 维度 | SLAM | 3D Gaussian Splatting |
|---|---|---|
| 核心问题 | **我在哪里？周围有什么？**（定位 + 建图） | **给定位姿，如何表示场景使得新视角渲染出真实图像？** |
| 输入 | Camera / LiDAR / IMU 等 | 通常多视角图像 + 相机位姿 |
| 位姿 | **核心输出之一** | 通常依赖已知/估计位姿 |
| 几何 | 点云 / Voxel / TSDF / Occupancy / Mesh / Landmarks | 3D Gaussian |
| 颜色/外观 | 可有可无（LiDAR 甚至只存 xyz/intensity） | **核心优化对象** |
| 新视角渲染 | 一般不是目标 | **核心能力** |
| 实时定位 | **非常重要** | 原始 3DGS 本身不是 SLAM |
| 地图 | 几何地图 | 可渲染场景 |

### 四、外观是分水岭

- **SLAM**：颜色是"附加属性"，不是地图优化的核心目标。纯 LiDAR SLAM 根本不关心颜色；RGB-D / Visual SLAM 才把 texture 贴上去。
- **3DGS**：Appearance 是核心，用**球谐函数（SH）**表示**视角相关颜色**——同一 Gaussian 从不同方向看颜色不同，因此能表现反光、光照、视角变化。

### 五、动态场景：从 3D 到 4D

- **传统 SLAM**：静态环境是地图，动态物体是干扰 → 检测出来、从地图中剔除（避免"车被当静态→车开走→地图出错"）。
- **Dynamic Gaussian Splatting**：动态物体不是噪声，而是场景的一部分，只是有自己的运动状态：

```
Static Gaussians（road/building/tree/红绿灯）
      +
Dynamic Gaussians（car A/B → 各自轨迹、pedestrian）
      +
Motion（时间维）
      ↓
Dynamic Scene（4D Scene Representation）
```

Gaussian 由此从 `(x,y,z,color)` 扩展出"位置+形状+颜色+透明度+时间+运动"。

### 六、把 Pylot + MMDetection3D + SLAM + Gaussian 串成技术链

```
Camera ─┐
LiDAR ──┼─→ SLAM/Localization → Pose ──→ Scene Representation ──→ 3D Scene ──→ Tracking/Planning
IMU ────┘                                        │
                                    Static Gaussian + Dynamic Gaussian
                                                        ↑
LiDAR ─→ MMDetection3D ─→ 3D Objects ─→ Static? / Dynamic? 分类
```

- **SLAM**：负责"我在哪 + 几何空间"。
- **MMDetection3D**：负责"空间里有什么 + 哪些在动"（动态分离）。
- **Gaussian**：负责"把这个空间以高质量可渲染形式表示出来"。

> **研究价值真正所在**：三者之间如何**共享位姿、几何、语义和动态信息**，而不是简单地把一个 SLAM 换成 Gaussian。
