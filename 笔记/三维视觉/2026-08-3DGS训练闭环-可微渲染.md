## 3D Gaussian Splatting 训练闭环总结（可微渲染）(2026.08)

> 来源：回答"3D Gaussian 怎么训练成能渲染出真实照片"时的核心推导。一句话：**随机挑一张训练图 + 对应相机位姿 → 把当前 Gaussian 场景从该视角渲染成 2D RGB → 与真实图算 Loss → 反向传播优化 Gaussian 参数**。这一步就是 **differentiable rendering（可微渲染）**。

### 一、训练闭环

```
训练集：多张 RGB 图 + 每张对应的相机位姿（来自 COLMAP/SfM）
                ↓
初始化 Gaussian Scene（来自 COLMAP 稀疏点云）
                ↓
随机选一张（如图像 583）+ 其 Pose 583
                ↓
Gaussian Rasterizer 渲染 → Rendered RGB
                ↓
与真实图 583 比较 → Loss
                ↓
Backpropagation → 更新所有 Gaussian
                ↓
下一轮再随机选另一张，循环
```

### 二、Gaussian 怎么变成 RGB（不是简单投影点）

- 简单投影 3D 点只得到稀疏的点，而真实图片是连续像素。
- 3DGS 把每个 **3D Gaussian 投影到相机平面**，变成一张 **2D 椭圆 Gaussian**，splat 到一片像素区域，并按**深度和透明度**混合。
- 所以一个 Gaussian 影响**一片像素**，而不是一个像素；一个像素通常被**多个 Gaussian 叠加**覆盖（车表面多个 + 背景）。

### 三、核心公式：Alpha 合成

对某个像素，按深度排序后有 N 个 Gaussian：

```
C = Σ(i=1..N) T_i · α_i · c_i        （c=颜色, α=不透明度）
T_i = Π(j=1..i-1) (1 - α_j)          （到达第 i 个前光线剩余的透射率）
```

直觉：A 挡掉 80% → 剩 20% 给 B → B 再贡献一部分 → 剩下的给 C → 最后得到像素 RGB。

### 四、视角相关颜色（SH）

- Gaussian 颜色用**球谐函数（SH）**表示，不是固定 RGB。
- Renderer 先算出"当前相机 → Gaussian 的观察方向"，喂给 SH → 得到该方向下的颜色。
- 所以同一 Gaussian 从不同方向看颜色不同 → 能表现反光/光照。

### 五、Loss 与反向传播

- Loss：`L = (1-λ)·L_D-SSIM + λ·L1`（像素级 L1 + 结构相似度）。
- 梯度反传同时优化 **Position / Shape（协方差）/ Opacity / Appearance（SH）**：
  - 车位置偏 → 改 Position；
  - 颜色暗 → 改 SH；
  - 太透明/太厚 → 改 Opacity / Shape / Scale。

### 六、为什么必须要有 Camera Pose

随机选图不够，还必须知道**这张图是从哪、以什么方向拍的**：

```
Image + 内参 K + 外参 (R,t) + Gaussian Scene → Renderer → Rendered Image
```

- COLMAP/SfM 在 3DGS pipeline 里提供两样东西：**Camera Poses + 初始稀疏点云**。

### 七、完整链路一句话

> **多张照片 → COLMAP 提供位姿+稀疏点云 → 初始化 Gaussian → 随机取一图+位姿 → 可微渲染成 2D RGB → 与真实图算 Loss → 反向传播更新位置/形状/透明度/SH → 循环。**

### 八、和 SLAM/COLMAP 的关系

**SLAM/COLMAP 负责"我从哪里看、场景大概在哪里"，Gaussian 负责"从这个位置看应该长什么样"并优化场景表示**——两者天然互补，这也解释了为什么 3DGS 和 SLAM/COLMAP 关系紧密。
