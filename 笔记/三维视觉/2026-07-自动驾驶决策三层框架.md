## 11. 自动驾驶决策三层框架 (2026.07)

> 来源：梳理自动驾驶感知-规划-决策的整体架构

### 三层次总览

```
整体规划（提前建模 + 路网信息）  →  当前时刻（瞬时感知）  →  未来决策（预测与规划）
        ↓                              ↓                          ↓
   "这条路是什么样的"           "现在周围有什么"           "接下来会发生什么"
```

### 层次1：整体规划（静态+先验信息）

**数据来源：** 高精度地图 + 路网导航

| 类型 | 内容 | 特点 |
|------|------|------|
| 高精度地图 | 车道线、路沿、红绿灯坐标、限速值 | 厘米级，提前加载，不受天气影响 |
| 路网信息 | 最优路径、实时路况、路口预告 | 覆盖几公里到几十公里 |

**核心**: 静态环境模型，回答"这条路是什么样的"。不可反映施工、事故等实时变化。

### 层次2：当前时刻（瞬时感知）

**数据来源：** BEV、摄像头、激光雷达、毫米波雷达

| 信息 | 示例 |
|------|------|
| 动态物体 | 前车距离12米，相对速度-5km/h；行人右前方3米横穿 |
| 自车状态 | 车速60km/h，方向盘0°，油门30% |

**核心**: 动态环境快照，回答"现在周围有什么"。视野有限（~200米），受天气光线影响。

### 层次3：未来决策（预测与规划）

**数据来源：** 层次1 + 层次2 → 综合推导

| 时间尺度 | 内容 | 示例 |
|----------|------|------|
| 毫秒级 | 控制指令 | 油门/刹车/转向 |
| 秒级（1-5s） | 避障、跟车 | 前车减速→松油门 |
| 10秒级（5-30s） | 变道、转弯 | 前方右转→提前变道 |
| 分钟级 | 路线选择 | 导航重新规划 |
| 小时级 | 行程规划 | 目的地到达时间预估 |

**核心**: 综合所有信息预测未来，回答"接下来该怎么走"。

### 协同示例：高速出口场景

```
层次1（地图）：前方3公里出口，限速120→80，出口前1公里有实线
        ↓
层次2（BEV）：当前左二车道，右侧50米有卡车，车速120km/h
        ↓
层次3（决策）：
  → 现在：保持车道，匀速
  → 10秒后：打灯，观察右侧，准备变道
  → 30秒后：变到右车道，松油门减速到80，准备出高速
```

### 代码抽象

```python
class AutonomousDrivingSystem:
    def __init__(self):
        self.hd_map = load_hd_map()         # 层次1: 静态
        self.route = get_navigation_route()
    
    def update(self, frame_data):
        self.bev = generate_bev(frame_data)  # 层次2: 实时感知
        self.ego_state = get_vehicle_state()
        return self.decide()                 # 层次3: 综合决策
    
    def decide(self):
        # 短期: 检查碰撞风险 → 紧急制动
        # 中期: 500米内路口 → 提前准备变道
        # 长期: 剩余距离 < 1km → 准备到达
        return control_command()
```

### 本质

三层不是独立模块，而是时间维度上的递进：

- **整体规划** = 静态环境，宏观路线
- **当前时刻** = 动态环境，瞬时状态  
- **未来决策** = 综合两者，预测+规划

三者关系：从宏观到微观，从静态到动态，从当前到未来。
