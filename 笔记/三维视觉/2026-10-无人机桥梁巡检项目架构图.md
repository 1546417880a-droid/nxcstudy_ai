	所属：机器人/无人机 桥梁巡检 实景三维重建 构件分割 航线规划 灾害识别
	描述：两趟飞行（先建模、后检测）的完整流程，核心是"先拿到带标签的构件模型，再基于模型生成检测航点"。
	架构图：
┌─────────────────────────────────────────────────────┐
│ 第一趟飞行：数据采集                                  │
│   - 无人机先飞一遍，采集图像/点云                     │
│   - 目的：拿到原始数据，用于建模                      │
└─────────────────────────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────────────────┐
│ 模型构建                                              │
│   - 三维重建（SfM/MVS 或 LiDAR 点云）                 │
│   - 生成实景三维/BIM/CAD 模型                         │
└─────────────────────────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────────────────┐
│ 构件分割（AI + 人工）                                 │
│   - AI 自动分割梁、柱、墙、板等                       │
│   - 人工校验修正                                      │
│   - 输出：带标签的构件模型                            │
└─────────────────────────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────────────────┐
│ 建模航线设置（基于模型）                              │
│   - 对每个构件：位置/方向/视角/距离                   │
│   - 生成全局检测航点序列                              │
└─────────────────────────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────────────────┐
│ 第二趟飞行：检测执行                                  │
│   - RTK 定位到构件位置                                │
│   - 实时局部规划（避障/风扰）                         │
│   - 按预设方向/视角拍照                               │
└─────────────────────────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────────────────┐
│ 灾害识别                                              │
│   - 对照片跑算法                                      │
│   - 定位到具体构件                                    │
│   - 生成报告                                          │
└─────────────────────────────────────────────────────┘

1、传感器自身坐标系 （雷达到相机）（相机、IMU、GNSS到车体）多个外参统一到 body车体自身坐标系 跟着车动，原点在车后轴/质心 odom 里程计坐标系启动时刻的车体位置建立的坐标系  map坐标系 局部地图原点坐标系
