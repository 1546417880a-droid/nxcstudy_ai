> 来源：梳理内参 fx = F / pixel_size 的来龙去脉。一句话：**像高 h 和焦距 F 在同一张成像平面上，h 就是 F 按相似三角形比例 H/Z 缩放出来的，所以 h 是 F 的 H/Z 倍；把 h 换算成像素数时 F 又被 pixel_size 除掉，于是得到 fx × (H/Z)。**

### 一、物理量先对齐（所有量都在"成像平面"上） 
「像素坐标系 → 成像平面物理坐标 → 相机坐标系 → 世界坐标系」

| 符号 | 含义 | 量纲 |
| :--- | :--- | :--- |
| **H** | 物体的真实高度 | 米 / mm（世界系） |
| **Z** | 物体到相机的距离（深度） | 米 / mm（世界系） |
| **F** | 焦距（光心到成像平面的距离） | mm（**成像平面上**） |
| **h** | 物体在成像平面上成的**像高** | mm（**成像平面上**） |
| **pixel_size** | 单个像素的物理尺寸 | mm / 像素（**成像平面上**） |
| **fx** | 内参 = F / pixel_size | 像素（量纲被除掉了） |

关键：**F 和 h 是同一条线段上的两个长度**（都在成像平面这个物理平面上），所以它们之间可以直接比。

### 二、相似三角形 → h 是 F 的 H/Z 倍

```
        物体                         成像平面
        ┌──┐ H                     ┌─┐ h
        │  │                       │ │
        └──┘                       └─┘
         ╲                         ╱
          ╲                       ╱
           ╲                     ╱
            ╲___________________╱
                  光心 O
              ├──── Z ────┤  ├─ F ─┤
```

由相似三角形（三角形 O-物体 vs 三角形 O-像）：

```
h / F = H / Z

→  h = F × (H / Z)
```

**这就是"h 相对于 F 的比例"这句话的意思**：h 和 F 在同一张成像平面上，h = F 乘以一个纯比例因子 (H/Z)。**h 是 F 的 H/Z 倍。**

### 三、从物理像高 h 换算到像素数

相机传感器把物理长度切成一个个像素，所以：

```
像素数 = h / pixel_size
       = [ F × (H/Z) ] / pixel_size
       = (F / pixel_size) × (H/Z)
       = fx × (H/Z)
```

### 四、为什么 h 能用 fx 来表示（核心一句）

> **h 和 F 在同一张成像平面上，h 是 F 的 H/Z 倍；所以"把 F 除以 pixel_size 得到 fx"这件事，等价于"把 h 除以 pixel_size 得到像素数"——两者被同一个 scale 变换（÷pixel_size）作用了一次，比例关系不变。**

推广到 2D（u、v 两个方向独立各除一次）：

```
u = fx × (X / Z) + cx
v = fy × (Y / Z) + cy
其中 fx = F / pixel_size_x，fy = F / pixel_size_y（通常相等）
```

### 五、一句话记忆 + 常见误区

**记忆**：`h/F = H/Z`（相似三角形）→ `h = F·H/Z`（像高）→ `pixels = h/pixel_size = fx·H/Z`（像素数）。**全程只有一个比例 H/Z，fx 只是把"毫米"翻译成"像素"的汇率。**

| 误区 | 纠正 |
| :--- | :--- |
| 以为 fx 是"焦距的像素表示"，所以有三个焦距 | 只有**一个**物理焦距 F。"fx / fy"只是水平/垂直方向像素尺寸不同导致的两次单位换算 |
| 以为公式是 F·H/Z 直接得像素数 | **量纲不对**：F·H/Z 是**毫米**（物理像高 h），必须再 ÷ pixel_size 才得到像素 |
| 以为 Z 变大像变小是因为 fx 变了 | fx 是**内参、出厂固定**；像变小是因为比例因子 H/Z 变小 |
| 以为"h 是 F 的 H/Z 倍"是近似 | 针孔模型下这是**精确**的相似三角形关系 |
