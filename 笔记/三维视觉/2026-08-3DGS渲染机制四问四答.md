## 3DGS 渲染机制四问四答（观察方向 / 透明度 / 透射率 / Shape与Opacity）(2026.08)

> 来源：围绕"3DGS 渲染时这些参数到底各自干什么"的四个追问整理。结论先行：**Position 决定投到哪里，Shape 决定影响多大/什么形状，Opacity 决定影响有多强，T_i 是累计透射率（不是独立参数）。**

### Q1 相机看 Gaussian 的方向怎么确定？是"光心→中心"连线吗？

**对。** 观察方向 = 光心 O → Gaussian 中心 μ 的单位向量：

```
d = (μ - O) / |μ - O|
```

- 用途：把方向喂给 **SH** → 得到该方向下的颜色（所以同一 Gaussian 从不同方向看颜色不同）。
- 细节：实际实现会按约定做世界/相机坐标系处理、符号约定，但**概念上"光心→中心"就是观察方向**。

### Q2 Opacity 是固定的吗？

**不是，是可优化参数** α_i。

- 训练中梯度会推动它变化：这里该是实墙 → 增大到 ~0.85；这里该是背景 → 减小到 ~0.05；接近 0 的会被 **pruning** 掉。
- 含义：**"这个 Gaussian 有多大程度遮挡/贡献它覆盖到的像素"**。

### Q3 T_i 透射率是怎么决定的？

**T_i 不是 Gaussian 自己的参数**，而是根据它**前面所有** Gaussian 的 opacity 累计算出来的：

```
T_i = Π(j=1..i-1)(1 - α_j)
```

含义：**"光线一路走到第 i 个 Gaussian 时，还剩多少"**。必须先按**深度排序（front→back）**才知道谁在前。

数值例子（A=0.5, B=0.3, C=0.8，按深度从前到后）：

| Gaussian | T（剩余透射率） | 实际贡献 T·α |
|---|---|---|
| A | 1 | 0.50 |
| B | 1-0.5 = 0.5 | 0.15 |
| C | (1-0.5)(1-0.3) = 0.35 | 0.28 |
| 背景 | (1-0.5)(1-0.3)(1-0.8) = 0.07 | 背景色×0.07 |

最终颜色 = 各贡献之和。

### Q4 Position / Shape / Opacity 各自干什么？

| 参数 | 回答的问题 | 作用 |
|---|---|---|
| **Position** | 我在哪？ | 中心**投影到哪个 pixel** |
| **Shape**（Scale+Rotation=协方差 Σ） | 我覆盖多大区域？ | 投影成 2D 椭圆，决定**影响哪些像素 + 权重分布**（中心权重大、边缘小） |
| **Opacity** | 我有多"实"？ | 决定这个影响**有多强** |
| **SH/Appearance** | 从这个方向看我是什么颜色？ | 视角相关颜色 |

**精确公式**：像素的 effective alpha = Gaussian weight × α_i（不透明度），权重由投影后的 2D Gaussian 密度决定。

### 渲染流水线（全部串起来）

```
3D Gaussian（Position/Shape/Opacity/SH）
   ↓ Camera projection
2D Gaussian splats
   ↓ Depth sorting（front → back）
Alpha compositing（C = Σ T·α·c）
   ↓
RGB Image
   ↓ 与 Ground Truth 比较 → Loss → Backprop → 更新 Position/Shape/Opacity/SH
```

> 一句话记忆：Gaussian = **"空间里的一个有位置、有形状、有透明度、有外观的软点"**——Position 决定投到哪，Shape 决定覆盖多大，Opacity 决定多实，SH 决定从某方向看是什么颜色。

### 下一步值得深挖的点

> "3D Gaussian 的 covariance 为什么投影后变成 2D 椭圆，以及 2D Gaussian 到底怎么算某个 pixel 的权重"——这个弄明白，3DGS 的 rasterizer 就基本通了。

### 完整理解总结（自己梳理的版本）

**Position** 决定 Gaussian 在 3D 空间中的位置，因此经过相机投影后决定它在图像中的中心位置；同时 **Position 和 Camera 的位置共同决定观察方向**，用于计算该 Gaussian 在当前视角下的 Appearance/SH 颜色。

**Shape**（协方差、尺度、旋转）决定 Gaussian 投影到图像后覆盖多大的区域，以及不同像素位置上的 Gaussian 权重。

**Opacity** 决定这个 Gaussian 本身的透明度，再和它在某个像素上的 Gaussian 权重结合，得到该 Gaussian 对这个像素的实际 alpha/贡献。

然后按照 Gaussian 到相机的深度，**从前到后进行 alpha compositing**；每个 Gaussian 的贡献还要乘以前面所有 Gaussian 剩下的透射率 T，最终把所有 Gaussian 的贡献累积起来得到这个像素的 RGB。
