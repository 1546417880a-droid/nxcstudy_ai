> 来源：追问"没有深度是不是就得用双目测距、是不是靠这个触发 ABS"。一句话：**双目只是纯视觉测距的一条路线，单目也能测距（地面假设 / 已知尺寸 / 深度估计 / 时序三角化 / 网络回归）；量产纯视觉常用"多摄像头 + 时序 + 神经网络"的组合，距离是学出来的；而 ABS 靠轮速传感器，视觉测距服务的是 AEB/ACC。**

### 一、双目：最直接的几何测距

两个镜头、基线 `b` 已知，同一物体在左右图的像素横坐标差为**视差** `d`：

```
Z = (f · b) / d
```

- 视差越大物体越近，越小越远。

| 优点 | 缺点 |
| :--- | :--- |
| 纯几何、不需学习、物理可解释；纹理丰富、光照良好时精度不错 | 需精确标定 + 立体匹配；弱纹理/重复纹理/光照差/远距离时匹配困难；**远距离视差极小 → Z 对 d 误差极其敏感**（Z 与 d 成反比）；基线有限，测距范围受限 |

> 双目是经典路线，但**不是唯一路线**。

### 二、单目 + 几何假设

#### （1）地面平面假设 + IPM

若目标在地面上（前车、车道线），且已知相机高度 `h`、俯仰角、地面为平面，则**像素射线与地面平面求交**解出深度 `Z`，再变到车体系——这就是**逆透视变换（IPM）**。

- ✅ 不需要双目、不需要深度学习、几何清晰；
- ❌ 只对地面上的点有效，对空中/悬空/坡道/颠簸场景不成立。

#### （2）已知物体尺寸

假设前车真实宽度 `W`（比如所有车宽约 1.8 m），图像上量出像素宽度 `w`：

```
Z ≈ (f · W) / w
```

- ✅ 单目即可、简单；
- ❌ 尺寸假设不一定成立（卡车、摩托、不同车型），误差大，只能粗估。

### 三、单目 + 深度学习

#### （1）单目深度估计

网络对每像素预测 `Z`，再 `[X_c,Y_c,Z_c]ᵀ = Z_c·K⁻¹[u,v,1]ᵀ`，经外参变到车体系。

**问题：尺度不确定**——单张图无法区分"很近的小物体"和"很远的大物体"，网络只能学相对深度或依赖数据先验的绝对深度，泛化性和精度有限。

#### （2）目标检测 + 距离回归

网络检测到前车，**直接回归它的距离**（训练时用 LiDAR/双目/真值距离监督）。很多量产纯视觉方案是这条路线：

- 输出 = 检测框 + 类别 + **距离 + 速度**；
- 距离由网络回归，**不靠几何公式**；
- ✅ 单目即可、端到端、能处理非地面目标；
- ❌ 本质是学出来的先验，遇到训练分布外场景（罕见车型、极端光照、遮挡）可能失效；可解释性差；需大量标注。

### 四、单目 + 时序：运动恢复结构（SfM）

相机在运动时，连续帧之间可提供视差：

- 上一帧到当前帧相机移动了已知距离（由轮速/IMU 提供）；
- 同一物体在两帧中的像素位移，提供类似双目的视差；
- 用**三角化/多视图几何**恢复深度。

也叫运动恢复结构（SfM）或"视觉里程计 + 三角化"。

- ✅ 单目即可、利用时序；
- ❌ 需足够相机运动（**静止或低速时退化**）；需精确位姿估计；对动态物体、弱纹理、快速运动鲁棒性差；计算复杂。

### 五、量产纯视觉实际怎么做

特斯拉这类量产"纯视觉"方案通常是**多摄像头 + 时序 + 神经网络**的组合，而不是单纯依赖某一种几何方法：

- 多摄像头（前视、侧视、后视）提供不同视角；
- 时序信息提供运动视差；
- 神经网络学习深度/距离/速度；
- 用大量车队数据做监督训练；
- 输出 **BEV 下的 3D 目标、距离、速度**，而不是从单个像素用公式算出来的。

> 既不是传统双目，也不是单目几何公式，而是**数据驱动的多视角 + 时序 3D 感知**。

### 六、澄清：ABS 不靠视觉，"能测前车距离就触发 ABS"这个说法不准确

ABS（制动防抱死）主要靠**轮速传感器**判断车轮是否抱死，**不需要视觉测距**。视觉测距服务的是：

| 功能 | 依赖 |
| :--- | :--- |
| AEB（自动紧急制动） | 前车距离 + 相对速度 |
| ACC（自适应巡航） | 前车距离 + 相对速度 |
| 前碰撞预警 | 前车距离 + 相对速度 |

正确的分工是：**视觉测距 → 触发制动请求 → ABS 再根据轮速决定是否介入防抱死。**

### 七、六条路线对比

| 方法 | 需要什么 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- |
| **双目** | 两个相机 + 标定 | 纯几何、可解释 | 远距离差，纹理弱失效 |
| **单目 + 地面假设** | 相机高度/俯仰 | 简单，地面目标有效 | 只对地面点有效 |
| **单目 + 已知尺寸** | 物体尺寸假设 | 简单 | 尺寸假设不准 |
| **单目深度估计** | 网络 | 单目即可 | 尺度不确定，泛化差 |
| **单目 + 时序 SfM** | 运动 + 位姿 | 单目即可 | 静止/低速退化，复杂 |
| **多摄像头 + 网络** | 多视角 + 时序 + 数据 | 量产主流，鲁棒 | 需大量数据，可解释性差 |

### 八、一句核心总结

> **纯视觉测距不一定要双目。** 双目用视差做几何测距，单目可以用地面假设、已知尺寸、深度估计、时序三角化或神经网络回归来测距。**量产纯视觉方案通常是多摄像头 + 时序 + 神经网络的组合，距离是学出来的，不是从单个像素用公式算出来的。** 而 **ABS 本身靠轮速传感器**，视觉测距主要用于 AEB/ACC 等前向碰撞功能。
