(3D视觉-传感器-传感器数据增加-几何原理) 1、对极几何：单目两帧为什么能恢复相机运动（2026.09）

来源：梳理"两张图 → 匹配点 → 本质矩阵 E → 分解出 R、t"的完整空间解释。
一句话：同一个空间点在两帧里各给出一条视线射线，这两条射线必须相交；两射线相交 ⇔ 它们与基线共面 ⇔ 存在极平面 ⇔ 匹配点落在极线上。写成代数就是 x2ᵀ E x1 = 0，每对匹配点给一个方程，够多就能解出 E，而 E = [t]× R 里就装着 R 和 t。

────────────────────────────

一、几何元素总览：五点、三线、一极平面、两像平面、两极线

先把图画清楚，后面所有推导都只是这张图的代数化。

五点

P　　空间中的一个真实 3D 点：在两帧里被看到，位置未知（深度未知）
O1　第一帧相机光心：第一帧相机坐标系的原点
O2　第二帧相机光心：由 R、t 决定其在第一帧坐标系中的位置，O2 = -Rᵀt
p1　P 在第一帧像平面上的投影：已知（像素坐标）
p2　P 在第二帧像平面上的投影：已知（与 p1 匹配得来）

三线

O1P（即射线 O1→p1）　第一帧视线射线，P 在这条线上，深度未知
O2P（即射线 O2→p2）　第二帧视线射线，P 也在这条线上
基线 O1O2　两个光心的连线，长度 = 平移量 ‖t‖

三线关系：两条视线射线必须交于 P；两条视线射线 + 基线共面。

两个面 + 两条线

极平面　由 O1、O2、P 三点确定的平面（等价于由 O1O2 与任一视线确定）
两像平面　第一帧像平面、第二帧像平面
极线 l1　极平面 ∩ 第一帧像平面，p1 必在其上
极线 l2　极平面 ∩ 第二帧像平面，p2 必在其上

顺带（可选）：基线 O1O2 与两个像平面的交点叫极点 e1、e2；所有极线都过对应的极点。

空间关系示意：

       P (空间点，深度未知)
      /  \
     /    \          两条视线射线 O1P、O2P 必须交于 P
    /      \
  O1--------O2        基线 O1O2（长度 = ‖t‖，方向 = t）
   \        /\
    \      /  \   ← 极平面：由 O1、O2、P 张成
     [像1]    [像2]
      l1       l2     ← 极平面与两个像平面的交线 = 两条极线
      p1       p2     ← 匹配点分别落在自各的极线上

────────────────────────────

二、单张图为什么没有深度

- 像素 p1 只确定一条射线 O1→p1。
- 空间点 P 在这条射线上，但具体在哪一点不知道（远近都投到同一个像素）。
- 所以单目一张图无法定 3D。

────────────────────────────

三、两张图为什么能定运动

同一个空间点 P：

- 在第一帧：P 在射线 O1→p1 上；
- 在第二帧：P 在射线 O2→p2 上。

如果 p1、p2 是正确匹配，那么这两条射线必须交于 P。

两帧匹配点的空间含义 = 两条视线射线必须相交。

────────────────────────────

四、为什么要先统一坐标系

谈"射线相交"，必须把两个相机放到同一个坐标系里。通常选第一帧相机坐标系为世界坐标系：

第一帧光心　O1 = 0
第一帧射线方向（归一化像平面坐标）　x1 = K⁻¹ p1
第二帧光心　O2 = -Rᵀ t
第二帧射线方向（变到第一帧）　Rᵀ x2，其中 x2 = K⁻¹ p2

于是两条射线都画在同一个坐标系里：

L1:  λ · x1
L2:  -Rᵀt + μ · Rᵀx2

令它们相交（联立消去 λ、μ），即得：

x2ᵀ [t]× R x1 = 0
x2ᵀ E  x1 = 0       其中  E = [t]× R

（[t]× 是 t 的反对称矩阵，[t]× a = t × a。）

────────────────────────────

五、极平面与极线

- O1、O2、P 三点确定一个平面 → 极平面。
- 极平面与第一帧像平面交出一条线 → 第一帧极线 l1。
- 极平面与第二帧像平面交出一条线 → 第二帧极线 l2。
- 匹配点 p1 必在 l1 上，p2 必在 l2 上。

关键：极平面由 O1、O2 和第一帧射线 L1 决定，不需要知道 P 在 L1 上的具体深度。

这正是对极约束有用的原因：深度未知也能给出约束——p2 不必全图搜索，只需在 l2 这一条线上搜。

────────────────────────────

六、为什么知道 R、t 就能算出第二帧极线

给定 R、t：

1. 第二帧光心 O2 = -Rᵀt；
2. 给定第一帧像素 p1 → 第一帧射线 L1: λ x1；
3. 基线 O1O2 与射线 L1 确定极平面；
4. 极平面与第二帧像平面相交 → 第二帧极线 l2。

R、t 决定基线 → 基线 + 第一帧射线决定极平面 → 极平面决定第二帧极线。

代数上：l2 = E x1（E x1 就是第二帧极线的齐次线方程；同理 l1 = Eᵀ x2）。

────────────────────────────

七、为什么能解出 R、t

每一对匹配点都满足 x2ᵀ E x1 = 0，未知的是 E：

- 一对点给一个线性方程；
- E 有 9 个元素，尺度自由，加上行列式为 0 的约束，实际 5 个自由度（去掉尺度 8 个，再减去 det E = 0 的 1 个）；
- 所以一般 8 对点即可线性解出 E（八点法），再用 SVD 投影回秩 2 的矩阵。

解出 E 后，由 E = [t]× R 做分解（SVD）：

- 得到 4 组候选 (R, t)；
- 其中 t 只有方向、没有尺度（单目尺度不确定，只知道相对比例，不知道真实米数）；
- 用"三角化后点必须在两个相机前方（正深度）"筛出唯一正确的一组。

────────────────────────────

八、最终总结（最小逻辑链）

单张图：一个像素 → 一条射线，深度未知。

两张图：同一个空间点 → 两条射线，两条射线必须相交。

两条射线相交
  ⇔ 它们与基线共面
  ⇔ 极平面存在
  ⇔ 匹配点落在极线上
  ⇔ x2ᵀ E x1 = 0

每对匹配点给一个方程  →  足够多（≥8）→  解出 E
E = [t]× R           →  分解   →  两帧之间的旋转 R 和平移 t（t 只到尺度）

这就是单目两帧能恢复相机运动的完整空间解释。

────────────────────────────

附：和前后环节的衔接

前端提特征 + 匹配　得到 p1 ↔ p2 匹配点对
本节：对极几何　匹配点对 → E → R、t（外参，t 尺度未知）
三角化　已知 R、t + 匹配点对 → 恢复 P 的 3D 坐标（点云）
PnP（双目/RGB-D 或有地图后）　3D 点 + 2D 像素 → 直接解位姿，替代对极几何

(3D视觉-传感器-传感器数据增加-几何原理) 2、针孔模型：为什么 z·(u,v,1)ᵀ = K·(x,y,z)ᵀ（2026.09）

来源：最原始、最笨、不跳步地把"一条光线"推成内参矩阵，重点回答"为什么尺度因子 s 可以写成 z"；再补上这个公式在实际代码里到底拿来干嘛（反投影）。
一句话：像素只记录方向 (x/z, y/z)，不记录距离；把 u = fx·x/z + cx 两边乘以 z，左边自然剩下公共因子 z，所以那个尺度因子不是假设的，它就是 3D 点在相机坐标系下的深度。反过来用（一~七小节推出来的式子），补上深度 z 就能把像素反投影回 3D 点（八~十三小节）。

────────────────────────────

一、先忘掉矩阵，只想一件事：光线

相机光心在 O，空间中有一个点 P = (x, y, z)。

从 O 出发、穿过 P 的光线继续往前走，最终打在成像平面上，形成一个像素 (u, v)。

现在问一个最简单的问题：

如果把 P 沿着这条光线往外移，比如移到 2P = (2x, 2y, 2z)，它的像素坐标会变吗？

答案：不会。

因为 2P 和 P 在同一条光线上，光心看到的还是同一个方向，打在成像平面上的还是同一个 (u, v)。

这就是透视投影的本质：

像素 (u,v) 只和方向有关，和距离无关。

────────────────────────────

二、那像素到底记录了什么？

像素 (u,v) 记录的是这个方向：

  x/z ,  y/z

为什么是这两个比值？

- x 是横向偏移；
- y 是纵向偏移；
- z 是深度；
- 离得越远（z 越大），同样的 x 看起来越小；
- 所以真正决定像素位置的是 x/z 和 y/z。

内参矩阵 K 干的事，就是把这个方向 (x/z, y/z) 换算成像素坐标：

  u = fx · (x/z) + cx
  v = fy · (y/z) + cy

到这里，没有任何矩阵，全是几何。

────────────────────────────

三、把这两个式子变成矩阵（逐步）

第一步：把分母 z 乘到左边

  u = fx·(x/z) + cx

两边乘 z：

  u·z = fx·x + cx·z

同理：

  v·z = fy·y + cy·z

第二步：再加一个恒等式

还有一个显然成立的式子：

  z = z

也就是：

  1·z = 0·x + 0·y + 1·z

第三步：把三个式子摞起来

  u·z = fx·x + 0 ·y + cx·z
  v·z = 0 ·x + fy·y + cy·z
    z = 0 ·x + 0 ·y +  1·z

写成矩阵：

  [ u·z ]   [ fx  0  cx ] [ x ]
  [ v·z ] = [  0 fy  cy ] [ y ]
  [  z  ]   [  0  0   1 ] [ z ]

右边那个 3×3 矩阵就是 K。

────────────────────────────

四、关键的一步：左边可以提出 z

看左边：

  [ u·z ]
  [ v·z ]
  [  z  ]

三项都含有 z，所以可以提出来：

  [ u·z ]       [ u ]
  [ v·z ] = z · [ v ]
  [  z  ]       [ 1 ]

于是：

      [ u ]       [ x ]
  z · [ v ] = K · [ y ]
      [ 1 ]       [ z ]

────────────────────────────

五、回答最初的疑问：为什么 s 可以写成 z？

为什么尺度因子 s 可以写成 z？

因为在这个推导里，左边提出来的那个因子，本来就是 z。

它不是"假设"的，也不是"定义"的，而是从 u·z = fx·x + cx·z 两边乘 z 之后，自然出现在左边的：

- 第一行左边是 u·z；
- 第二行左边是 v·z；
- 第三行左边是 z。

三项的共同因子就是 z。所以 z·(u,v,1)ᵀ 里的这个 z，就是那个 3D 点的深度。

一句话：

  z 不是凭空冒出来的尺度因子，而是在把透视除法 u = fx·x/z + cx 两边乘以 z 之后，左边自然剩下的那个公共因子；物理上它就是 3D 点在相机坐标系下的深度。

────────────────────────────

六、换个角度：如果不乘 z 会怎样？

如果不乘 z，我们只能写：

  [ u ]            [ x ]
  [ v ]  ~  K ·    [ y ]
  [ 1 ]            [ z ]

这里的 ~ 意思是"相差一个未知的尺度因子"。

为什么有未知尺度因子？

因为像素 (u,v) 只记录方向、不记录距离，所以 (x,y,z) 和 (2x,2y,2z) 给出同一个 (u,v)。为了让等号成立，就必须补一个尺度因子——而在针孔模型里，这个尺度因子恰好就是 z。

────────────────────────────

七、最终总结

1. 像素只记录方向 (x/z, y/z)；
2. 内参 K 把方向变成像素 (u,v)；
3. 把 u = fx·x/z + cx 两边乘 z，得到 u·z = fx·x + cx·z；
4. 三行摞起来，左边是 (u·z, v·z, z)ᵀ；
5. 左边提出公共因子 z，得到 z·(u,v,1)ᵀ；
6. 所以 z·(u,v,1)ᵀ = K·(x,y,z)ᵀ。

这个 z 就是深度，不是假设，是推导出来的。

────────────────────────────

八、这个公式到底拿来干嘛：2D 关键点 → 3D 点

前面七节把公式推出来了，但还没说它用来干什么。真正容易卡住的其实是这一步——不是推导，而是"这公式到底拿来干嘛"。

看代码里的第一步标题：

  第一步：2D 关键点 → 3D 点

这说明整个流程的目标是：

  手上有一张图，图上标了一些 2D 关键点（比如人体关节的像素坐标 (u,v)），
  要把这些 2D 点变成相机坐标系下的 3D 点 (x,y,z)。

函数 _project_2d_kpts_to_3d 干的就是这件事。

为什么需要这个转换？

在 3D 人体姿态估计、动作捕捉、AR/VR 里，最终想要的是：

  人体关节在真实 3D 空间中的位置，而不是它们在图像上的像素位置。

对比一下：

2D 关键点　左肩在像素 (320, 180)
3D 点　左肩在相机前方 2.3 米，往右 0.15 米，往上 0.4 米

只有后者才能拿去做动作分析、驱动虚拟人、算关节角度。

所以需要一个函数，把 2D 像素反推回 3D 空间。

────────────────────────────

九、但 2D → 3D 本身是不可能的

一张 2D 图像的一个像素，对应的是空间中的一条射线，不是唯一的 3D 点。

就像闭上一只眼看一个点，没法判断它离你多远。

所以必须补一份额外信息，常见的有三种：

深度图 / 深度值 z　直接反投影
双目 / 多视图　三角化
人体骨骼先验 / 模型　优化拟合

_project_2d_kpts_to_3d 用的是第一种：

  已知每个 2D 关键点的深度 z，反投影得到 3D 点。

（这正好呼应第 1 节：单张图一个像素 → 一条射线，深度未知就定不了 3D；这里是把深度补上了，射线才退化成一个点。）

────────────────────────────

十、反投影：把公式反过来用

回到推导出来的那个式子：

      [ u ]       [ x ]
  z · [ v ] = K · [ y ]
      [ 1 ]       [ z ]

- 左边：知道像素 (u,v)，也补上了深度 z；
- 右边：K 是相机内参，已知；
- 未知：(x,y,z)。

反解：

  [ x ]            [ u ]
  [ y ] = K⁻¹ · z ·[ v ]
  [ z ]            [ 1 ]

这一步就是 _project_2d_kpts_to_3d 的核心。

输入　2D 关键点 (u,v)、深度 z、相机内参 K
输出　相机坐标系下的 3D 点 (x,y,z)

────────────────────────────

十一、几何意义：从像素射出一条光线，走到深度 z

用空间的话说：

1. 像素 (u,v) 决定了从相机光心出发的一条光线方向；
2. K⁻¹(u,v,1)ᵀ 把这个方向还原到相机坐标系；
3. 深度 z 告诉你沿着这条光线走多远；
4. 走到的那个点，就是 3D 点 (x,y,z)。

所以这个公式不是"凭空变出 3D"，而是：

  在已知深度的前提下，把 2D 像素反投影回 3D 空间。

────────────────────────────

十二、为什么代码里必须先做这一步

因为后面的步骤都需要 3D 点，而不是 2D 像素：

- 计算 3D 关节角度；
- 拟合人体骨架；
- 投影到另一个视角；
- 和 3D 模型对齐。

所以整个 pipeline 的第一步就是：

  2D 关键点 + 深度 → 3D 点

而这个转换的数学工具，就是针孔相机模型的反投影公式。

────────────────────────────

十三、一句话总结

  在已知像素坐标 (u,v) 和深度 z 的情况下，反推出该点在相机坐标系下的 3D 位置 (x,y,z)。

它是 2D 关键点变成 3D 点的桥梁。没有它，就只剩一堆像素坐标，做不了任何 3D 的事。

────────────────────────────

附：和前后环节的衔接

本节：针孔模型（正投影）　3D 点 (x,y,z) → 像素 (u,v)，尺度因子 = 深度 z
本节：反投影（第八~十三小节）　像素 (u,v) + 深度 z → 3D 点 (x,y,z)，即 _project_2d_kpts_to_3d
去畸变 / 归一化像平面　x = K⁻¹ p，把像素还原成方向 (x/z, y/z, 1)
与第 1 节衔接　对极几何里的 x1 = K⁻¹p1、x2 = K⁻¹p2，用的就是本节这个 K
外参 [R|t]　把世界坐标系的点变到相机坐标系，再送进本节这个 K 投影成像素

(3D视觉-传感器-传感器数据增加-几何原理) 3、像素—内参—深度—外参：谁管什么、各自从哪来（2026.10）

来源：整理"像素坐标 / 内参 / 深度 / 外参"四者的分工，并补全内参、深度、外参各自的来源清单。
一句话：内参管"射线方向"，深度管"射线上多远"，外参管"这条射线在全局坐标系的哪里"；投影是 x ~ K[R|t]X，反投影 K⁻¹x 只给出射线方向，必须再补一个深度，多射线求交才得到 3D 点。

────────────────────────────

一、四个量各管什么

像素坐标　观测：图像上看到的点
内参 K　　像素 ↔ 射线：当前相机的投影 / 反投影
深度 z　　射线上的距离：决定 3D 点在射线上的位置
外参 [R|t]　相机 ↔ 世界：统一坐标系，把不同时刻 / 相机对齐
空间交点　多射线交会：SfM 和双目求 3D 点的原理

一句话：内参管"射线方向"，深度管"射线上多远"，外参管"这条射线在全局坐标系的哪里"。

────────────────────────────

二、投影与反投影：整条链

投影（3D → 2D）：

  x ~ K [R | t] X

- 外参 [R|t]：世界 → 相机；
- 内参 K：相机 → 像素。

反投影（2D → 射线）：

  x̂ = K⁻¹ x

得到相机坐标系下的射线方向，但深度未知——这正是第 2 节说的"像素只记录方向 (x/z, y/z)、不记录距离"。

求 3D 点，要补两样：

- 一个深度：告诉你在射线上走多远；
- 一个外参：把这条射线放到统一的坐标系里。

────────────────────────────

三、深度（z）从哪来

双目 / 多目三角化　两条以上射线求交：被动，需要基线，尺度由基线定
SfM 三角化　多视图特征点求交：被动，尺度不确定
结构光　投射已知图案、解相位：主动，近距离精度高
ToF（飞行时间）　测光往返时间：主动，实时，中远距离
激光雷达 LiDAR　激光扫描测距：主动，精度高，有绝对尺度
毫米波雷达 Radar　测距：主动，穿雾强，精度较低

(3D视觉-传感器-传感器数据增加-几何原理) 4、世界→相机→像素：完整投影链条（一般形式 + 矩阵形式）（2026.10）

来源：把"世界坐标系 → 相机坐标系 → 像素坐标系"整条链拆开写，每一步都给出标量分式形式和矩阵形式，最后汇总成常用最终形式。
一句话：世界→相机是一步刚体变换（Xc = R·Xw + t），相机→像素是一步透视除法加内参（u = fx·x/z + cx，v = fy·y/z + cy）；合起来就是 z·(u,v,1)ᵀ = K[R|t]·(Xw,Yw,Zw,1)ᵀ，左边那个 z 就是相机坐标系下的深度。标量分式适合理解几何含义，矩阵形式适合代码实现和多步变换，两者完全等价。

────────────────────────────

一、世界坐标系 → 相机坐标系（刚体变换）

设世界坐标点 Xw = (Xw, Yw, Zw)，相机坐标点 Xc = (x, y, z)。

一般形式（展开写）：刚体变换，先旋转再平移

    x = r11·Xw + r12·Yw + r13·Zw + tx
    y = r21·Xw + r22·Yw + r23·Zw + ty
    z = r31·Xw + r32·Yw + r33·Zw + tz

其中 R = (rij)₃ₓ₃ 是旋转矩阵，t = (tx, ty, tz)ᵀ 是平移向量。

矩阵形式

    (x, y, z)ᵀ = R · (Xw, Yw, Zw)ᵀ + t

齐次形式

    (x, y, z, 1)ᵀ = [ R  t ; 0  1 ] · (Xw, Yw, Zw, 1)ᵀ

（[R t ; 0 1] 是 4×4 的齐次变换矩阵，也叫外参矩阵。）

────────────────────────────

二、相机坐标系 → 像素坐标系（针孔模型）

相机坐标点 (x, y, z) 投影到像素 (u, v)。内参：

    K = [ fx   0   cx
           0  fy   cy
           0   0    1 ]

其中 fx、fy 是焦距（像素单位），cx、cy 是主点。

一、一般形式（先做透视除法，再乘焦距加主点）

    u = fx · x/z + cx
    v = fy · y/z + cy

这就是最原始、最直白的投影公式：像素只和方向 x/z、y/z 有关，和距离 z 无关。

二、矩阵形式（两边乘 z 后）

    z · (u, v, 1)ᵀ = K · (x, y, z)ᵀ

展开就是：

    u·z = fx·x + cx·z
    v·z = fy·y + cy·z
        z = z

三、齐次比例形式（不显式写 z）

    (u, v, 1)ᵀ  ~  K · (x, y, z)ᵀ

符号 ~ 表示"相差一个未知尺度因子"。在针孔模型里这个尺度因子就是 z。

────────────────────────────

三、世界坐标系 → 像素坐标系（完整链条）

把上面两步合起来。

一、一般形式（展开写）：先做外参变换，再做透视投影

    x = r11·Xw + r12·Yw + r13·Zw + tx
    y = r21·Xw + r22·Yw + r23·Zw + ty
    z = r31·Xw + r32·Yw + r33·Zw + tz

    u = fx · x/z + cx
    v = fy · y/z + cy

合并成一步：

    u = fx · (r11·Xw + r12·Yw + r13·Zw + tx) / (r31·Xw + r32·Yw + r33·Zw + tz) + cx

    v = fy · (r21·Xw + r22·Yw + r23·Zw + ty) / (r31·Xw + r32·Yw + r33·Zw + tz) + cy

这是最完整的标量形式：没有矩阵、没有齐次坐标，全是分式。

二、矩阵形式（常用最终形式）

    z · (u, v, 1)ᵀ = K · [ R  t ] · (Xw, Yw, Zw, 1)ᵀ

或者写成投影矩阵 P：

    P = K · [ R  t ]        （3×4）

    z · (u, v, 1)ᵀ = P · (Xw, Yw, Zw, 1)ᵀ

三、齐次比例形式

    (u, v, 1)ᵀ  ~  P · (Xw, Yw, Zw, 1)ᵀ

────────────────────────────

四、常用最终形式汇总

    场景                        | 公式
    相机坐标 → 像素（一般形式）  | u = fx·x/z + cx，v = fy·y/z + cy
    相机坐标 → 像素（矩阵）      | z·(u,v,1)ᵀ = K·(x,y,z)ᵀ
    世界坐标 → 像素（一般形式）  | u = fx·(r11·Xw+r12·Yw+r13·Zw+tx)/(r31·Xw+r32·Yw+r33·Zw+tz) + cx，v 同理
    世界坐标 → 像素（矩阵）      | z·(u,v,1)ᵀ = K[R t]·(Xw,Yw,Zw,1)ᵀ   ← 最常用
    世界坐标 → 像素（投影矩阵）  | z·(u,v,1)ᵀ = P·(Xw,Yw,Zw,1)ᵀ，P = K[R t]
    齐次比例形式                | (u,v,1)ᵀ ~ K[R t]·(Xw,Yw,Zw,1)ᵀ

────────────────────────────

五、一句话总结

    世界 → 相机：Xc = R·Xw + t
    相机 → 像素：u = fx·x/z + cx，v = fy·y/z + cy
    合起来最常用：z·(u,v,1)ᵀ = K[R t]·(Xw,Yw,Zw,1)ᵀ

一般形式适合理解几何含义，矩阵形式适合代码实现和多步变换。两者完全等价。

────────────────────────────

附：和前后环节的衔接

外参 [R|t]　把世界坐标系的点变到相机坐标系（本节第一步）
内参 K　　把相机坐标系的点透视投影成像素（本节第二步）
投影矩阵 P = K[R|t]　两步合成一个 3×4 矩阵，3D 标定里的"标定矩阵"
第 2 节：针孔模型　本节第二步就是那一节的内容，只是这里第一次把外参接在它前面
第 3 节：内参/深度/外参　外参管坐标系、内参管射线方向、深度 z 管射线上多远，这里体现为：外参在前、内参在后、z 只出现在分母/尺度因子上

(3D视觉-传感器-传感器数据增加-几何原理) 5、像素→相机→世界：完整反投影链条（一般形式 + 矩阵形式）（2026.10）

来源：把"像素坐标系 → 相机坐标系 → 世界坐标系"整条链拆开写，每一步给出标量形式和矩阵形式，并说明已知条件与几何含义。
一句话：反投影的核心前提是"像素只给方向，不给距离"，必须补一个深度 z 才能得到唯一的 3D 点；先 x = (u-cx)/fx·z、y = (v-cy)/fy·z 得到相机坐标，再用 Xw = Rᵀ(Xc - t) 转回世界坐标，合起来就是 Xw = Rᵀ(z·K⁻¹(u,v,1)ᵀ - t)。和上一节正好互为逆运算，区别只在于：反投影必须额外知道深度。

────────────────────────────

零、符号约定

    (u, v)              像素坐标
    (x, y, z)           相机坐标系下的 3D 点
    (Xw, Yw, Zw)        世界坐标系下的 3D 点
    K                   内参矩阵
    R, t                外参（世界→相机）
    z                   相机坐标系下的深度

反投影的核心前提：像素只给方向，不给距离，必须补一个深度 z 才能得到唯一的 3D 点。

────────────────────────────

一、像素坐标系 → 相机坐标系

已知：像素 (u, v)、深度 z、内参 K。

一、一般形式（最直白）：从正投影公式出发

    u = fx · x/z + cx，v = fy · y/z + cy

反解 x、y：

    x = (u - cx)/fx · z
    y = (v - cy)/fy · z
    z = z

这就是最常用的单目反投影公式。

二、矩阵形式

    (x, y, z)ᵀ = z · K⁻¹ · (u, v, 1)ᵀ

其中：

    K⁻¹ = [ 1/fx    0    -cx/fx
              0   1/fy    -cy/fy
              0     0        1    ]

三、几何含义

    1. 像素 (u,v) 决定从光心出发的一条射线方向
    2. K⁻¹(u,v,1)ᵀ 把这个方向还原到相机坐标系
    3. 深度 z 告诉你沿射线走多远
    4. 走到的点就是 (x, y, z)

────────────────────────────

二、相机坐标系 → 世界坐标系

已知：相机坐标 (x, y, z)、外参 R, t。

一、一般形式：正变换是 Xc = R·Xw + t，反解 Xw：

    Xw = R⁻¹(Xc - t)

因为 R 是正交矩阵，R⁻¹ = Rᵀ，所以：

    Xw = Rᵀ(Xc - t)

展开成标量：

    Xw = r11·(x - tx) + r21·(y - ty) + r31·(z - tz)
    Yw = r12·(x - tx) + r22·(y - ty) + r32·(z - tz)
    Zw = r13·(x - tx) + r23·(y - ty) + r33·(z - tz)

注意：这里 rij 是 R 的元素，转置后行变成列，所以系数顺序要对应好（第一行系数是 r11、r21、r31，不是 r11、r12、r13）。

二、矩阵形式

    (Xw, Yw, Zw)ᵀ = Rᵀ · ( (x, y, z)ᵀ - t )

齐次形式：

    (Xw, Yw, Zw, 1)ᵀ = [ Rᵀ  -Rᵀ·t ; 0  1 ] · (x, y, z, 1)ᵀ

────────────────────────────

三、像素坐标系 → 世界坐标系（完整链条）

已知：像素 (u, v)、深度 z、内参 K、外参 R, t。

一、一般形式（合并两步）

先反投影到相机坐标：

    x = (u - cx)/fx · z，y = (v - cy)/fy · z，z = z

再变换到世界坐标：

    Xw = r11·(x - tx) + r21·(y - ty) + r31·(z - tz)
    Yw = r12·(x - tx) + r22·(y - ty) + r32·(z - tz)
    Zw = r13·(x - tx) + r23·(y - ty) + r33·(z - tz)

把 x、y 代入即可得到只含 (u, v, z) 的表达式：

    Xw = r11·( (u-cx)/fx·z - tx ) + r21·( (v-cy)/fy·z - ty ) + r31·(z - tz)
    Yw = r12·( (u-cx)/fx·z - tx ) + r22·( (v-cy)/fy·z - ty ) + r32·(z - tz)
    Zw = r13·( (u-cx)/fx·z - tx ) + r23·( (v-cy)/fy·z - ty ) + r33·(z - tz)

二、矩阵形式（常用最终形式）

    (Xw, Yw, Zw)ᵀ = Rᵀ · ( z · K⁻¹ · (u, v, 1)ᵀ - t )

如果写成一步到位的齐次形式：

    (Xw, Yw, Zw, 1)ᵀ = [ Rᵀ  -Rᵀ·t ; 0  1 ] · ( z·K⁻¹·(u,v,1)ᵀ , 1 )ᵀ

不过实际代码里通常分两步写，更清晰。

────────────────────────────

四、常用最终形式汇总

    方向          | 一般形式                             | 矩阵形式
    像素 → 相机   | x=(u-cx)/fx·z，y=(v-cy)/fy·z，z=z     | (x,y,z)ᵀ = z·K⁻¹·(u,v,1)ᵀ
    相机 → 世界   | Xw = Rᵀ(Xc - t)                       | Xw = Rᵀ(Xc - t)
    像素 → 世界   | 先算 x、y，再代入 Xw = Rᵀ(Xc - t)      | Xw = Rᵀ( z·K⁻¹·(u,v,1)ᵀ - t )

────────────────────────────

五、几何链条（反投影）

    像素 (u, v)
        │  补深度 z
        ▼
    相机坐标 (x,y,z) = z · K⁻¹ · (u,v,1)ᵀ
        │  外参逆变换
        ▼
    世界坐标 (Xw,Yw,Zw) = Rᵀ( (x,y,z)ᵀ - t )

────────────────────────────

六、一句话总结

    像素 → 相机：x = (u-cx)/fx·z，y = (v-cy)/fy·z；矩阵形式 Xc = z·K⁻¹·(u,v,1)ᵀ
    相机 → 世界：Xw = Rᵀ(Xc - t)
    合起来：Xw = Rᵀ( z·K⁻¹·(u,v,1)ᵀ - t )

整个反投影的关键前提始终是：必须已知深度 z。没有 z，像素只能确定一条射线，不能确定唯一的 3D 点。

附：和前后环节的衔接

本节：反投影　像素 (u,v) + 深度 z → 相机坐标 → 世界坐标，即 _project_2d_kpts_to_3d 的完整链条

第 2 节：针孔模型（十、反投影）　本节把那一节的反投影补上了外参那一段，形成像素直通世界坐标的完整链
第 3 节：内参/深度/外参　再次体现"深度 z 是唯一不能由相机自己给出的量"——反投影少了它整条链断在第一步

(3D视觉-传感器-传感器数据增加-几何原理) 6、射线形式：像素只给方向，不给距离（2026.10）

来源：补充反投影的另一种等价表达——射线参数方程，它最清楚地表达了"一个像素对应一条从光心出发的射线，而不是一个点"。
一句话：像素 (u,v) 经过 K⁻¹ 得到一个方向向量 d = K⁻¹(u,v,1)ᵀ，相机系下射线就是 Xc(λ) = λ·d，世界系下把光心平移和外参转置加上即可：Xw(λ) = -Rᵀt + λ·RᵀK⁻¹(u,v,1)ᵀ；反投影公式就是射线形式在 λ = z 处的取值。射线形式不需要深度，给的是整条线；反投影需要深度，给的是唯一的点。

────────────────────────────

一、为什么需要射线形式

反投影的本质是：一个像素对应一条从光心出发的射线，而不是一个点。

    已知深度 z　→ 射线退化成唯一一个 3D 点
    不知深度　　→ 只能得到这条射线的方向和参数方程

射线形式就是用参数方程把这个"方向 + 起点"写出来。

────────────────────────────

二、相机坐标系下的射线形式

一、一般形式

已知像素 (u, v) 和内参 K，但不知道深度。

从光心 Oc = (0, 0, 0) 出发，经过像素 (u, v) 对应的方向向量是：

    d = K⁻¹ · (u, v, 1)ᵀ = ( (u - cx)/fx ,  (v - cy)/fy ,  1 )ᵀ

于是相机坐标系下的射线参数方程为：

    Xc(λ) = λ · d = λ · ( (u - cx)/fx ,  (v - cy)/fy ,  1 )ᵀ ,   λ ≥ 0

其中 λ 是沿射线的参数。

二、和深度 z 的关系

对比反投影公式：

    x = (u - cx)/fx · z，y = (v - cy)/fy · z，z = z

可以看到：

    λ = z

也就是说，参数 λ 就是相机坐标系下的深度 z。当 λ = z 时，射线上的点就是那个唯一的 3D 点。

所以射线形式和反投影形式是同一件事：反投影 = 射线 + 已知深度。

三、归一化方向形式

有时希望方向向量第三个分量为 1（上面已经满足）；有时希望它是单位向量：

    d̂ = d / ‖d‖

那么射线写成：

    Xc(s) = s · d̂ ,   s ≥ 0

此时 s 是沿射线的物理距离，不再等于深度 z。

（区分：λ 是"沿 z 轴方向的深度"，s 是"沿射线的真实距离"。除 d 为单位向量外，两者一般不相等。）

────────────────────────────

三、世界坐标系下的射线形式

已知相机外参 R, t，相机光心在世界坐标系下的位置是：

    Ow = -Rᵀ · t

方向向量要从相机坐标系转到世界坐标系：

    dw = Rᵀ · d = Rᵀ · K⁻¹ · (u, v, 1)ᵀ

于是世界坐标系下的射线参数方程为：

    Xw(λ) = Ow + λ · dw = -Rᵀt + λ · Rᵀ K⁻¹ (u, v, 1)ᵀ ,   λ ≥ 0

同样，当 λ = z（相机坐标系深度）时，这个点就是反投影得到的世界坐标点。

验证：λ = z 时确实回到反投影公式

代入 λ = z：

    Xw(z) = -Rᵀt + z · Rᵀ K⁻¹ (u, v, 1)ᵀ
          = Rᵀ ( z · K⁻¹ (u, v, 1)ᵀ - t )

这正是第 5 节写的像素 → 世界的反投影公式。所以射线形式是反投影公式的"未补深度版本"。

────────────────────────────

四、和正投影的呼应

正投影：

    z · (u, v, 1)ᵀ = K [R t] · (Xw, Yw, Zw, 1)ᵀ

可以理解为：世界点 Xw 和光心 Ow 连成一条射线，这条射线与像素平面交于 (u, v)。

反投影射线：

    Xw(λ) = Ow + λ · dw

则是反过来：从像素 (u, v) 出发，还原出这条射线。两者是同一几何关系的正反两个方向。

────────────────────────────

五、常用最终形式汇总

    形式              | 表达式
    相机系射线（一般） | Xc(λ) = λ · ( (u-cx)/fx , (v-cy)/fy , 1 )ᵀ ,  λ ≥ 0
    相机系射线（矩阵） | Xc(λ) = λ · K⁻¹ (u,v,1)ᵀ

    反投影（已知深度） | Xw = Rᵀ ( z K⁻¹ (u,v,1)ᵀ - t )
    单位方向           | d̂ = d/‖d‖，Xc(s) = s·d̂，s 为沿射线物理距离

六、一句话总结

    射线形式：Xc(λ) = λ K⁻¹ (u,v,1)ᵀ；世界系下是 Xw(λ) = -Rᵀt + λ Rᵀ K⁻¹ (u,v,1)ᵀ

    核心区别：射线形式不需要深度，给的是整条射线；反投影需要深度，给的是唯一一个 3D 点

这样，正投影、反投影、射线三种形式就完整了：

    正投影　点 → 像素
    反投影　像素 + 深度 → 点
    射线　　像素 → 一条线

(3D视觉-传感器-传感器数据增加-几何原理) 7、对极几何 / 三角化 / PnP / BA：四者的分工（2026.10）

来源：回答两个疑问——"PnP 怎么算出外参"和"BA 和三角化的'最小代价'是不是一回事"。
一句话：对极几何（2D-2D）和 PnP（3D-2D）都是求位姿但输入不同；三角化是"位姿固定、求点"，BA 是"位姿和点都放开、全局一起求"；四者顺序是 对极几何 → 三角化 → PnP → BA。

────────────────────────────

一、PnP 怎么算出外参

PnP（Perspective-n-Point）解决的问题是：已知 n 个三维空间点 X_i 及其在图像上的二维投影 x_i，求相机位姿（R, t）。

它和对极几何的根本区别在于输入不同：

  方法        输入                        输出
  对极几何    两张图像上的 2D-2D 匹配点    相对位姿 R, t（差一个尺度）
  PnP         三维点 + 其二维投影（3D-2D） 相机绝对位姿 R, t（含尺度）

求解思路：对每个 3D-2D 对应，投影关系给出

  x_i ~ K [R | t] X_i

把它展开并消去深度，每个点对可以提供 2 个关于 R, t 的约束方程；点数足够即可解出位姿。常见解法：

  DLT / P3P    用少量点直接代数求解，给出初值
  EPnP         把三维点表示为 4 个控制点的加权和，转为求控制点在相机系下的坐标，线性求解
  迭代法 / 非线性最小二乘  以代数解为初值，最小化重投影误差

    min_{R,t} Σ_i ‖ x_i − π(K, R, t, X_i) ‖²

注意最后这一步——PnP 的迭代精化，形式上和 BA 对单个相机位姿的优化是一样的，只是它固定三维点、只优化一个位姿。这也是容易混淆的地方。

关键点：PnP 需要已知的三维点。在 SfM 流程中，这些三维点通常来自前面的三角化。所以典型顺序是：对极几何求初始相对位姿 → 三角化得到初始三维点 → 后续新图像用 PnP（3D-2D）求绝对位姿 → 再三角化新点 → 最后 BA 全局优化。

────────────────────────────

二、BA 和三角化的"最小代价"是不是一回事

不是一回事。两者都在最小化重投影误差，但优化变量和规模完全不同。

三角化：固定位姿，只优化一个点

相机位姿 R, t 已知且固定，只求一个三维点 X：

    min_X  Σ_{j 看到该点的相机} ‖ x_ij − π(P_j, X_i) ‖²

  未知量：只有 X_i（3 个自由度）
  每条观测是一个约束，多个视角的视线"最小代价地交于一点"
  是局部、小规模问题，甚至可用线性方法（DLT）近似闭式求解

BA：位姿和点一起优化

把所有相机位姿和所有三维点同时作为未知量：

    min_{P_j, X_i}  Σ_{所有观测 (i,j)} ‖ x_ij − π(P_j, X_i) ‖²

  未知量：所有 P_j（每个 6 自由度）+ 所有 X_i（每个 3 自由度）
  是全局、大规模的非线性最小二乘，需要 LM + Schur 补来解
  它修正三角化得到的点，也修正对极几何 / PnP 得到的位姿，让整个重建在全局意义上自洽

一句话区分：

  三角化是"位姿固定，求点"；BA 是"位姿和点都放开，一起求"。

所以 BA 包含了三角化所做的事（它会优化三维点），但远不止于此——它还同时优化所有相机位姿，并且是在全局所有观测上联合进行。三角化的结果只是 BA 的输入初值之一。

────────────────────────────

三、用流程串起来

  1. 对极几何：2D-2D → 初始相对位姿（差尺度）
  2. 三角化：位姿固定 → 初始三维点
  3. PnP：已知三维点 + 新图 2D → 新相机绝对位姿
  4. BA：以 1、2、3 的结果为初值，同时优化所有位姿和所有点，最小化全局重投影误差

四者的分工：对极几何和 PnP 求位姿（输入不同），三角化求点（位姿固定），BA 是全局联合精化（位姿和点都放开）。

────────────────────────────

四、速查表

  方法      输入                   优化什么                规模
  对极几何  2D-2D 匹配             求 E，解出 R, t         小（两帧）
  三角化    位姿 + 2D 观测         只优化一个 3D 点 X      局部、小
  PnP       3D 点 + 2D 观测        一个相机位姿 R, t       小
  BA        所有位姿 + 所有点      位姿和点同时优化        全局、大

## 1. 先把符号对齐到你的图

- `p`：相机 A 里某个像素的**齐次坐标**，`p = (u, v, 1)ᵀ`
- `q`：相机 B 里对应像素的齐次坐标，`q = (u', v', 1)ᵀ`
- `F`：一个 **3×3 矩阵**（基础矩阵），待求

`qᵀFp` 的计算过程是：

```
Fp        → 得到一个 3 维向量，记作 l
qᵀ l      → 得到一个标量（q 和 l 的点积）
```

**关键理解**：`Fp` 算出来的这个 3 维向量 `l`，**就是相机 B 里那条极线的方程系数**。

一条二维直线在齐次坐标下的方程是 `l₁u' + l₂v' + l₃ = 0`，写成向量就是 `l = (l₁, l₂, l₃)`，而 `qᵀ l = 0` 正是"点 q 在这条直线 l 上"。

所以：

> **`qᵀFp = 0` 的意思是：`Fp` 算出相机 B 中的极线 l，而匹配点 q 恰好落在这条极线上。**

这就是你脑子里"p 的射线上的点必落在 B 的极线上"的**代数写法**。`F` 的作用就是：**输入 A 的一个像素 p，输出 B 里对应的那条极线 l**。

---

## 2. 为什么"落在线上"能写成 `qᵀFp=0`（几何推导直觉）

你已经接受"p 的射线 → B 的极线"这个事实。现在把它变成矩阵乘法：

**第一步：p 在 A 中定义了一条射线。**
用归一化坐标（先不管内参），p 的方向向量是 `p̂ = K⁻¹p`。这条射线上的任意 3D 点（在 A 坐标系下）可写成 `X = λ p̂`（λ 是深度）。

**第二步：把这条射线变换到 B 的坐标系。**
A→B 的相对变换是 `X_B = R X_A + t`。代入 `X_A = λ p̂`：

```
X_B = λ R p̂ + t
```

这条就是 A 的射线在 B 坐标系里的样子（一条直线）。

**第三步：这条直线在 B 的图像上投影成一条线（极线）。**
B 的投影是 `q ~ K_B X_B`。一条 3D 直线投影到图像上还是一条 2D 直线。可以证明，这条 2D 直线的系数是：

```
l = K_B⁻ᵀ (t × R) K_A⁻¹ p
```

（`t × R` 表示 t 的反对称矩阵乘 R，`[t]× R`。）

**第四步：q 必须在这条线上，即 `qᵀ l = 0`。** 代入上式：

```
qᵀ K_B⁻ᵀ [t]× R K_A⁻¹ p = 0
```

把中间那一坨记作 **F**：

```
F = K_B⁻ᵀ [t]× R K_A⁻¹
```

于是得到 **`qᵀFp = 0`**。

**所以这个式子不是凭空来的**：它就是把"p 的射线 → 变换到 B → 投影成极线 → q 在线上"这条几何链，一路用矩阵乘出来的结果。`F` 里**封装了 R、t 和内参**，但它只以"约束"的形式出现——你不需要先知道 R、t，就能用匹配点直接求 F。

（已标定时 `p̂=K⁻¹p, q̂=K⁻¹q`，中间变成 `E = [t]×R`，约束是 `q̂ᵀEp̂=0`，E 只含 R 和 t 方向。）

## 3. 回到你的困惑："找一个让最多对同时满足的 F"是什么意思

每个匹配对 `(pᵢ, qᵢ)` 都给一个方程：

```
qᵢᵀ F pᵢ = 0
```

这是一个关于 **F 的 9 个未知元素**的**线性方程**（因为 p、q 已知，F 是未知量，式子里是 F 元素的一次组合）。

- F 有 9 个元素，但整体乘一个常数不改变 `qᵀFp=0`（等式两边同乘常数仍为 0），所以**只有 8 个自由度**。
- 每个匹配给 1 个方程 → **8 组匹配**就能线性解出 F（这就是**八点法**）。
- 实际匹配有成百上千组，方程远超未知数 → 用最小二乘 / SVD 求"最满足"的 F。

**但错配（outlier）会污染最小二乘**。所以实际做法是 **RANSAC**：

1. 随机抽 8 组匹配 → 解出一个候选 F
2. 用这个 F 检查**所有**匹配：算 `|qᵢᵀFpᵢ|`，小于阈值就算"这条匹配符合这个 F"（内点）
3. 统计内点数；重复很多次，保留**内点最多**的那个 F
4. 用这个 F 的所有内点再做一次最小二乘精化

**"让最多对同时满足的 F"就是 RANSAC 选出的那个 F**——它最大程度地解释了匹配数据，同时把错配排除在外。这一步既是"估计 F"，也顺手完成了"几何验证"（内点=可靠匹配，外点=错配剔除）。

---

## 4. 一句话把三层串起来

| 层次 | 含义 |
|---|---|
| 几何直觉 | A 的像素 p 对应的射线，投到 B 上是一条极线；B 的匹配 q 必在这条线上 |
| 代数表达 | `Fp` = 这条极线的系数 l；`qᵀ l = 0` 就是"q 在 l 上" → `qᵀFp=0` |
| 求解 | 每个匹配给一个关于 F 的线性方程；8 个匹配解 F；RANSAC 选"内点最多"的 F 并剔错配 |

你已有的几何图像完全正确，`qᵀFp=0` 只是把它写成了"**F 把 A 的点映射成 B 的线，q 在这条线上**"的一次矩阵乘法。F 就是那个"点→线"的映射器。
