一、Q1：接进系统后，是不是用户态驱动解析、再按格式发出去？

**一句话答案：方向对，但漏了 ③ 内核这一层；而且“用户态驱动”要拆成两半——④ 解析和 ⑤ 发布，不同传感器在这两段里的份量完全不同。**

为什么：

- 物理线不会直接进用户态。CAN 进 `netdev`，相机进 `V4L2`，激光雷达进 `socket`；你写的节点第一行永远是 `open()` 或 `socket()`，拿到的是 fd，不是电平。中间那条 syscall 边界就是图上的橙虚线。
- **相机**：ISP 在 ③ 或专用硬件里就结束，用户态只做格式转换、打戳、发布，且多半零拷贝。
- **CAN**：帧解析在内核（SocketCAN），信号语义（DBC）常在中间件，两者都不是“驱动”干的。
- **激光雷达 / 毫米波**：私有协议解包确实在用户态 SDK 里——这一类最贴合原话。

容易记错：把“按格式发出去”理解成驱动随手拼结构体。实际格式是**契约**（`.msg` / IDL），由 ⑤ 适配层序列化；驱动只把字节翻译成带 `stamp` 和 `frame_id` 的测量，不做融合、不做理解。

判据：把 ROS 拔掉，它还能单独跑、还能吐数据吗？能 → 里面有一颗驱动核；不能 → “驱动 + 适配”揉在一起。

二、Q2：两个下游各做一次 rgb→车体系，重复了吗？要不要中转 topic？

**一句话答案：会重复，但“rgb→车体系变换”这个说法本身不成立——图像侧是投影 / 采样，不是刚体变换；消除重复的做法是一份 TF，不是搬一份数据。**

为什么：

- **点云**可以乘 4×4 刚体矩阵换到车体系；**图像**不行，像素没有深度，无法旋转平移。
- BEV 里方向是反的：把 BEV 网格上的 3D 点投影到图像平面采样特征（LSS 的 lift-splat、BEVFormer 的 reference point）。这叫 view transform。
- 所以“两个模块各变一次”应改成：两个模块各做了一次特征提升。真正重复的是 GPU 上的 lift 计算，不是矩阵乘法。

| 手段 | 适合什么 | 代价 |
|---|---|---|
| TF 树（static + dynamic） | 外参、位姿；点云 / 目标换系 | 几乎为零，默认选它 |
| 预处理 topic | 去畸变、deskew、同步打包 | 多一跳，只做一次 |
| 共享内存 / 零拷贝 | 多下游共享同一份大结果 | 复杂，跨机不可用 |

容易记错：

1. 以为可以 publish 一张“ego 系的图像”——不存在；能中转的只有去畸变后的图像，它仍在相机系。
2. 中转节点重新打时间戳——变换不改变采样时刻，时间戳必须原样透传。
3. 以为贵在矩阵乘法——10 万点的 4×4 是亚毫秒级；贵的是 6 MB 图像过 topic（单路 180 MB/s）。重复该消的是**带宽**。

另一个更隐蔽的坑：两个模块都“变到了 BEV”，但一个 ego-centric、一个 world-centric，网格分辨率也不同。外参再准也叠不上。统一表示的定义必须全局唯一。

三、Q3：“数据增加”是不是订阅原始 topic 产出新数据？算不算增广？

**一句话答案：这个形态成立，但它叫派生（derived data），不叫增广；而且按信息从哪来要分五类，不是“几何 + 预测”两类。**

| 类型 | 例子 | 信息从哪来 |
|---|---|---|
| 几何 | 双目视差、三角化、IPM、range image | 已有观测的重新组织，几乎不增信息 |
| 学习 | 单目深度、光流、分割、occupancy | 训练集注入的先验，有偏 |
| 规则 / 物理 | 轮速+IMU→里程计、GNSS+IMU→组合 | 运动学约束，误差随时间累积 |
| 多源融合 | 前 / 后 / 特征级融合、伪点云 | 唯一真正增加信息的（要求源独立） |
| 元数据 | 置信度、质量分、有效 mask、尺度因子 | 对数据本身的评估，跟随主数据 |

最容易漏的一条：**尺度**。单目深度模型输出多是相对深度 / 逆深度，没有绝对尺度，直接当米用就是全错；要靠已知基线、已知物体尺寸、地面假设，或与 LiDAR / 轮速对齐求 scale。双目受 `σZ = Z²/(fB)·σd` 约束，误差随距离平方增长：f=1000 px、B=0.5 m、Z=50 m 时，0.5 px 视差误差 ≈ 2.5 m。

容易记错：

1. 把学习派生的输出当**独立观测**——它和 LiDAR 的误差不独立，两个误差会同向灌进状态估计。
2. 把时间戳打成“推断完成时刻”——派生量描述的是输入那一刻的场景，时间戳必须继承输入；推断耗时另记 `latency`。
3. 用派生数据训练新模型、再派生数据——伪标签自举会让误差固化，需要 teacher 与一致性检查。
