# 扩散模型（Diffusion Model）核心机制串讲 (2026.07)

> 来源：围绕扩散模型的加噪过程、噪声本质、文本引导、训练推理的完整 Q&A

---

## 一句话总结

> **扩散模型的核心是"学会逆向"：正向是纯随机的逐步加噪（原图→纯噪声），每一步记录"加了什么噪声"；训练时让模型学会"给定带噪图+文本+时间步，预测噪声"；推理时从纯噪声出发，模型一步步预测并减去噪声，文本通过 Cross-Attention 控制去噪方向，最终生成符合描述的清晰图像。**

---

## 一、加噪过程：三个关键问题

### 1.1 噪声加在什么位置？

**每个像素、每个通道、无一遗漏。**

```
原图 (H×W×3)                    噪声 (H×W×3)              加噪后 (H×W×3)
┌─────────────────┐      ┌─────────────────┐      ┌─────────────────┐
│ R₀₀  R₀₁  R₀₂  │      │+0.3  -1.2  +0.8 │      │ R+0.3 R-1.2 R+0.8│
│ G₀₀  G₀₁  G₀₂  │  +   │-0.5  +0.1  -0.6 │  =   │ G-0.5 G+0.1 G-0.6│
│ B₀₀  B₀₁  B₀₂  │      │+1.1  -0.4  +0.2 │      │ B+1.1 B-0.4 B+0.2│
└─────────────────┘      └─────────────────┘      └─────────────────┘
  512×512×3 个值          512×512×3 次独立抽样            全覆盖
```

### 1.2 加的噪声值从哪里来？

**每个像素、每个通道独立从 N(0,1) 抽样，互不影响。**

```python
noise = torch.randn(3, 512, 512)  # 786,432 次独立抽样

# 位置 (0,0) R通道 → 抓到 0.32
# 位置 (0,0) G通道 → 抓到 -1.51
# 位置 (0,1) R通道 → 抓到 -0.23  （跟前一个毫无关系）
```

- 不是某个通道有自己的正态分布
- 是全局共享同一个 N(0,1)，但每个位置各自独立抽签
- 99.7% 的值在 [-3, 3] 之间

### 1.3 加噪公式：加权混合，不是直接加法

```python
# ✅ 真正的扩散过程：加权混合
x_t = √α_t * x_0 + √(1-α_t) * ε
#     ↑              ↑
#  原图逐渐减弱    噪声逐渐加强

# α_t 从 1 衰减到 0：
t=0:    α=1.000  →  x_0  = 1.0 × 原图 + 0.0 × 噪声  = 纯原图
t=1:    α=0.999  →  x_1  ≈ 0.9995×原图 + 0.03×噪声  ≈ 几乎还是原图
t=50:   α=0.900  →  x_50 ≈ 0.95×原图 + 0.32×噪声    = 能看出轮廓+雪花
...
t=T:    α=0.000  →  x_T  = 0.0 × 原图 + 1.0 × 噪声  = 纯噪声
```

两个权重 `√α` 和 `√(1-α)` 此消彼长，平方和始终为 1，保证整体方差稳定。

## 二、每一步都重新抽样，不是加一次就完事

```python
x_0 = 原图

# t=1: 从 N(0,1) 抓了一把新噪声 ε₁
x_1 = √0.999 * x_0 + √0.001 * ε₁

# t=2: 又从 N(0,1) 抓了一把全新的 ε₂
x_2 = √0.998 * x_1 + √0.002 * ε₂

# t=3: 再抓新的 ε₃
x_3 = √0.997 * x_2 + √0.003 * ε₃
...
# t=T: 纯噪声
```

**每一步基于上一步的结果，重新随机抽样，按当前时间步的权重混合。**

## 三、最后是纯噪声，中间步骤图什么？

**每一步都记录了 `(加噪后图像, 加的噪声)` 这对数据，这就是训练样本。**

```
t=1:  (x₁, ε₁)   ← 几乎是原图 + 极少噪声
t=2:  (x₂, ε₂)
...
t=T:  (x_T, ε_T)  ← 纯噪声
```

### 模型只做一个任务：预测噪声

```python
noisy_image = x_t          # 某个时间步的带噪图
true_noise = ε_t           # 这一步实际加的噪声（已记录）
timestep = t               # 当前第几步

predicted_noise = model(noisy_image, timestep)  # 模型猜噪声
loss = MSE(predicted_noise, true_noise)          # 跟真实噪声对比
loss.backward()                                  # 更新参数
```

**中间步骤 = 给模型提供不同"模糊程度"的训练样本，让它学会在任何噪声级别下都能认出噪声。**

### 推理时反过来用

```python
x_T = torch.randn(...)  # 纯噪声开始

for t in range(T, 0, -1):
    predicted_noise = model(x_t, t)           # 模型猜：这一步有多少噪声？
    x_{t-1} = denoise(x_t, predicted_noise)   # 减掉噪声，往清晰图走一步

# 循环结束 → x_0 ≈ 生成的清晰图像
```

### 随机性

- **正向加噪**：完全随机（噪声从 N(0,1) 抽样）
- **模型学习**：学习这个随机过程的**逆过程规律**——不管噪声怎么随机，都能认出它

## 四、文本引导（Classifier-Free Guidance, CFG）

### 4.1 训练时：随机 10% 丢掉文本

```python
image, text = batch
noisy_image = add_noise(image, noise, t)

# 关键：10% 概率把文本替换为空
if random.random() < 0.1:
    text_embedding = empty_text      # ← ""
else:
    text_embedding = text_encoder(text)  # ← 正常编码

predicted_noise = model(noisy_image, t, text_embedding)
loss = MSE(predicted_noise, true_noise)
```

| 输入条件 | 占比 | 模型学会 |
|---------|------|---------|
| "一只橘猫坐在沙发上" | 90% | 特定内容的噪声模式 |
| ""（空字符串） | 10% | 无条件、泛泛的噪声模式 |

### 4.2 推理时：差值放大文本影响力

```python
pred_uncond = model(x_t, t, empty_text)         # 无条件预测
pred_cond   = model(x_t, t, text_embedding)     # 有条件预测

# CFG：差值 × 放大系数
pred = pred_uncond + guidance_scale * (pred_cond - pred_uncond)
#                    ↑ 通常 7~9
```

**几何直觉**：
- `pred_cond - pred_uncond` = 文本特有的噪声模式
- 放大这个差值 = 更强烈地往文本方向推
- 不额外训练"评判模型"，所以叫 Classifier-Free

### 4.3 文本注入的位置：Cross-Attention

**加噪阶段**：文本完全不参与，噪声是纯随机的。

**模型预测阶段**：文本通过 Cross-Attention 注入：

```
带噪图 x_t ──→ U-Net Encoder ──→ ... ──→ U-Net Decoder ──→ 预测噪声
                     │              ↑        │
                     │    text_embedding      │
                     │         │              │
                     └─────────┼──────────────┘
                               │
                        Cross-Attention
                 Q=图像特征, K/V=文本特征
```

### 4.4 对比总结

| | 加噪（正向） | 去噪（反向/模型预测） |
|---|---|---|
| 文本参与？ | 不参与 | 参与（Cross-Attention） |
| 随机性？ | 完全随机 | 模型学到的确定性映射 |
| 目的 | 构造训练数据 | 学习噪声→清晰图的映射 |
| 公式 | √α·原图 + √(1-α)·ε | model(x_t, t, text) → ε_pred |

## 五、全链路流程

```
【训练】
原图+文本 → 随机抽样 t → 构造 x_t = √α·x₀ + √(1-α)·ε
    │                              │
    │                    90%: 编码文本    10%: 空文本""
    │                              │
    └──────────────────────────────┤
                                   ↓
                          model(x_t, t, text_embedding)
                                   ↓
                          loss = MSE(预测噪声, 真实噪声 ε)
                                   ↓
                              反向传播更新参数

【推理】
纯噪声 x_T + 文本 prompt
    ↓
for t in range(T, 0, -1):
    pred_uncond = model(x_t, t, "")
    pred_cond   = model(x_t, t, text_embedding)
    pred = pred_uncond + guidance_scale × (pred_cond - pred_uncond)
    x_{t-1} = denoise(x_t, pred)
    ↓
x_0 → 生成图像
```

## 六、核心要点速查

| 问题 | 答案 |
|------|------|
| 噪声加在什么位置？ | 每个像素、每个通道，全覆盖 |
| 噪声值从哪来？ | N(0,1)，每个位置独立抽样 |
| 加噪公式？ | `√α·原图 + √(1-α)·ε`（加权混合，非直接相加） |
| 每步噪声一样吗？ | 每步重新抽样，互不相关 |
| 最后纯噪声，中间步骤干嘛？ | 为每个"模糊程度"生成训练样本对 |
| 文本在哪注入？ | Cross-Attention（Q=图像，K/V=文本） |
| 加噪被文本引导吗？ | 不加噪纯随机，文本只引导去噪方向 |
| CFG 是什么？ | 训练时 10% 丢文本，推理时差值放大来增强文本控制 |
| 模型学什么？ | 学加噪随机过程的逆向规律：预测噪声 |
